# 2026-11-16 · Web 목업을 실제 웹 화면에 맞추고 시안 기준을 플랫폼별로 정함

- 이슈·PR: (이 PR)
- 커밋: (이 PR의 커밋)

> **요약** 웹 화면 8개와 Figma 목업 Web 줄을 비교했더니 실제 웹이 목업보다 기능이 많고 정책 문구와 상태 처리를 갖고 있었다. 그래서 웹은 구현을 기준으로 Web 목업을 다시 그렸고, iPhone·Android는 목업을 시안 기준으로 두었다. 기준은 `docs/design-system.md` 5.2절에 적었다.

## 사용 도구

- 도구: Claude Code (Claude Opus 5.5)
- 서브에이전트: 웹 화면과 목업 비교(읽기 전용)

## 요청

Figma에 그려진 대로 각 플랫폼 화면을 맞추는 방법을 물었다. 비교 결과를 본 뒤, 웹은 실제 화면에 맞추고 iOS·Android는 목업에 맞추기로 정했다.

## AI 산출물

- 웹 화면과 목업의 차이 조사: 구조 차이가 큰 화면은 볼트(목록·상세 2분할), 항목 상세(보기·수정 분리), 설정(그룹 구성), 계정 삭제(모달)
- `Tools/figma-builder/code.js`: Web 목업 8개를 실제 웹 구조와 문구로 다시 그림(인증 카드 384px, 사이드바 하단 메뉴, 볼트 2분할, 설정 3개 그룹과 세션 제어, 계정 삭제 모달)
- iPhone·Android 목업의 정책 문구를 정책과 같게 고침(가입 안내 SEC-001, 계정 삭제 제목·본문·확인 문구·버튼 SEC-005)
- `docs/design-system.md` 5.2절 "화면 시안의 기준", Figma 빌더 README

## 사람의 판단

- 웹은 구현을, iOS·Android는 목업을 기준으로 삼기로 했다.

## 검증하지 못한 것

- 실제 Figma에서의 모양. 웹 목업이 실제 웹과 얼마나 닮았는지는 브라우저 화면과 나란히 놓고 봐야 한다.
- Apple 화면을 목업에 맞추는 구현은 Mac에서 할 일이라 이번 범위가 아니다.
