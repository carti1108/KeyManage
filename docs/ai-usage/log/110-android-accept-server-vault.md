# 2026-11-20 · Android 되돌림 경고의 서버 볼트 받아들이기

- 이슈·PR: #3
- 커밋: 없음(커밋 전)

> **요약** 서버 볼트가 이전 상태로 돌아갔을 때 사용자가 확인하면 받아들이는 동작(VLT-001 규칙 9)을 Android의 저장·잠금 해제·로그인 직후 세 경로에 넣었다.

## 사용 도구

- 도구: Claude Code(Opus 5.5, Fable 5.2), Gradle
- 플러그인·스킬: 없음

## 요청

#152를 머지하고 에픽 #3을 닫은 뒤, 남아 있던 "서버 볼트 받아들이기" 버튼을 이어서 구현하라는 요청이었다.

## AI 산출물

- `:core:domain` `VaultSyncCoordinator.acceptRollback`: 마지막으로 본 revision을 경고에 담긴 서버 revision으로 낮추고 기기 기록에도 쓴다. 올리지는 않는다
- `:core:domain` `VaultSessionUseCase.unlock`: 동기화 오류로 끝날 때 볼트 키를 지운다
- `:feature:vaultlist`: 되돌림 안내 띠에 "서버 볼트 받아들이기"·"취소". 받아들이면 막혔던 저장을 다시 한다
- `:feature:unlock`, `:feature:root`: 되돌림 대화상자. 받아들이면 잠금 해제(비밀번호·생체)와 로그인 뒤 볼트 열기를 다시 한다
- `Scripts/check-policy-acceptance.sh`: 수락 테스트와 버튼 문구 검사

## 사람의 판단

| 판단 | 내용 |
| :--- | :--- |
| 지시 | 버튼 구현 진행 |
| AI 기본값 | 되돌림은 저장 때보다 로그인·잠금 해제 때 먼저 감지되고, 그 경로에서는 일반 오류 문구만 보여 서버에 연결된 채로는 볼트를 열 길이 없었다. 그래서 볼트 목록만이 아니라 세 경로 모두에 넣었다. 수락은 켜고 끄는 값이 아니라 경고에 담긴 revision 하나로 묶어, 서버가 더 낮은 값을 주면 다시 경고한다. 로그인 직후에는 사용자가 답할 때까지 볼트 키를 쥐고, 취소하면 지운다. |
