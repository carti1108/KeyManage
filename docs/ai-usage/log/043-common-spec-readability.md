> **요약** `vault-spec`·`api-spec`·`design-system`을 요약·표·번호 목록 구조로 바꿨다. 플랫폼별 암호 라이브러리, 토큰 바인딩, 글꼴, 아이콘 이름은 각 플랫폼의 `docs/platform-bindings.md`로 옮겼다. 코드와 문서가 참조하는 절 번호는 그대로 두었다.

- 도구: Claude Code (Claude Opus 5.5), GitHub CLI
- 플러그인·스킬: `project-docs:ai-usage`, 독립 리뷰 서브에이전트

## 요청

- PR 1(#73) 머지 뒤 #70의 두 번째 단계(공통 명세 정리)를 진행했다. 공통 명세의 플랫폼 세부를 함께 옮기는 것은 앞선 대화에서 사람이 정했다.

## AI 산출물

- `vault-spec.md`: 맨 위 요약과 주의, 전처리 세부 분리, `EncryptedVaultPayload`·`VaultData` 필드 표, 병합·호환 규칙 표
- `api-spec.md`: 엔드포인트 요약 표, 공통 규격 표, 오류 코드를 `상태 | 코드 | 메시지 | 조건` 표로, CORS 번호 목록
- `design-system.md`: 원칙·타이포그래피 표, 컴포넌트 5개 속성 표, 아이콘은 의미만 남김
- `Apps/Web`·`Apps/Apple`·`Apps/Android`의 `docs/platform-bindings.md`. Android 클라이언트는 아직 없지만 공통 명세의 Android 항목을 잃지 않으려고 `Apps/Android/docs/`를 만들었다.
- 절 번호 참조(약 70곳)를 조사해 참조되는 절 번호는 모두 유지했다.
