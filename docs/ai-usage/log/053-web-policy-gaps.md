# 2026-11-01 · 웹 정책 불일치 2건 수정(가입 안내, 오프라인 배너)

- 이슈·PR: 없음(PR 전)
- 커밋: ef472d0, 103711e, 7e8a671, 9cc495d, 638fdbf, a39fa5b

> **요약** 웹 기능이 정책대로 구현됐는지 정책 9개를 코드와 대조해 불일치 2건을 찾아 고쳤다. 가입 화면에 마스터 비밀번호를 잃으면 복구할 수 없다는 안내(SEC-001)를 넣고, 볼트가 열린 동안 네트워크가 끊기면 오프라인 배너(VLT-002)를 띄운다. 사람이 SEC-001 문구의 용어 정리를 승인했다.

## 사용 도구

- 도구: Claude Code (Opus 5.5). 정책 대조 서브에이전트 1개, 구현 서브에이전트 1개, 독립 리뷰 서브에이전트 1개
- 플러그인·스킬: policy-manager, project-docs:ai-usage

## 요청

웹 기능 구현이 다 끝났는지 물었다. 점검 결과로 나온 불일치 2건을 고치도록 했다.

## AI 산출물

- 정책 9개(SEC-001~003, VLT-001~003, GEN-001, COM-001~002)와 웹 코드 대조 결과: 불일치 2건, 웹 해당 없음 항목, 정책에 없는 흔한 기능 목록(마스터 비밀번호 변경, 내보내기 등)
- SEC-001 사용자 문구를 "마스터 키"에서 "마스터 비밀번호"로 바꾸고 가입 화면 표시로 명시
- 가입 화면 안내(`Alert`, 입력란 `aria-describedby` 연결), 문구 모듈 `authNotices.ts`
- 브라우저 연결 상태 어댑터(`networkStatus.ts`)와 훅(`useNetworkOffline`), 열린 볼트의 오프라인 배너 조건 확장

## 검증하지 못한 것

1. 실제 브라우저에서 네트워크를 끊어 배너가 뜨는지는 보지 않았다. 테스트는 연결 상태 값과 이벤트를 흉내 냈다.
2. 리뷰 반영 커밋의 2차 독립 리뷰는 하지 않았다.
3. 고치지 않은 LOW 2건: 연결이 오락가락할 때 배너 알림 영역이 다시 삽입돼 화면 낭독기가 불안정하게 읽을 수 있음, Apple 클라이언트의 같은 가입 안내(이 PC 범위 밖)
