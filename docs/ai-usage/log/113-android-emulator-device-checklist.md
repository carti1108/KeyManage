# 2026-11-20 · Android 기기 확인 목록을 에뮬레이터에서 확인

- 이슈·PR: #156, #157, #158, #159, #160
- 커밋: a2aa542

> **요약** Android 기기 확인 목록 49개를 AI가 에뮬레이터에서 접근성 트리와 adb 입력으로 확인하고 결과를 목록에 적었다. 통과 31, 실패 4, 일부 2, 미확인 12이며, 찾은 결함 5건을 이슈로 등록했다. 사람은 기본 흐름을 직접 눌러 본 뒤 특수 상황(오프라인, 되돌림, 다른 기기에서의 비밀번호 변경)을 AI에 맡겼다.

## 사용 도구

- 도구: Claude Code (Claude Fable 5.2), adb, uiautomator, Docker, gh
- 플러그인·스킬: 없음

## 요청

이전 세션의 인수인계 문서를 읽고 이어서 진행하라는 요청이었다. 인수인계 문서의 목표는 `Apps/Android/docs/device-checklist.md` 49개 항목을 에뮬레이터에서 확인해 결과를 그 파일에 적는 것이다.

## AI 산출물

- `Apps/Android/docs/device-checklist.md`에 확인 방법, 항목별 결과와 사유, 체크리스트 밖 관찰을 기록
- 결함 이슈 5건
  - #156 복사한 값이 30초 뒤에도 클립보드에 남는다(COM-001)
  - #157 목록 맨 아래에서 `+` 버튼이 마지막 줄의 복사 버튼을 가린다
  - #158 다른 기기에서 비밀번호가 바뀐 뒤 옛 비밀번호로 볼트가 안내 없이 열린다(SEC-003 규칙 11)
  - #159 화면을 돌리면 볼트가 잠기고 입력하던 내용이 사라진다
  - #160 웹: 다른 기기에서 비밀번호가 바뀐 뒤 잠금 해제가 끝나지 않는다
- 확인 방법
  - 화면은 `uiautomator dump`로 읽고 `adb shell input`으로 조작
  - "다른 기기"는 에뮬레이터 Chrome의 웹 클라이언트로 대신함
  - 오프라인은 `adb reverse --remove tcp:8080`으로 재현
  - 되돌림은 백엔드 컨테이너의 계정 볼트 파일을 한 revision 앞 사본으로 덮어써 재현
  - 계정 삭제 확인 문구(한글)는 임시 로컬 페이지의 글자를 복사해 붙여 넣음

## 검증하지 못한 것

1. 5장 생체 해제 5개와 7장의 생체 항목 1개: 기기 보안 설정을 바꾸지 않았다.
2. 다크 모드, 큰 글자, TalkBack, 키보드 가림: 화면을 보지 못한다.
3. 3장의 "30초 안에 다른 값 복사": #156 때문에 타이머가 돌지 않는다.
4. #158은 1회 관찰이다. #156과 #158의 원인은 코드 읽기로 추정했고 수정으로 확인하지 않았다.
5. #160이 데스크톱 브라우저에서도 나는지 확인하지 않았다.
6. 12자 이상이면서 약한 비밀번호로 가입이 막히는지 시험하지 않았다.

## AI의 오류와 정정

| 오류 | 발견 | 조치 |
| :--- | :--- | :--- |
| 서버 연결을 끊은 직후 저장에 오프라인 경고가 없자 결함으로 의심했다. 실제로는 살아 있던 연결로 저장이 전송된 것이었다. | AI, 서버 접속 불가와 저장 로직을 대조하다가 | 앱을 다시 띄워 확인했고 경고가 정상으로 나왔다. 목록에 주의 문구를 적었다. |
| 키보드로 배치가 바뀐 화면에서 이전 좌표를 눌러 로그아웃 버튼이 눌렸고, 이어서 테스트 계정의 비밀번호가 이메일 칸에 평문으로 입력돼 세션 출력에 남았다. | AI, 다음 화면을 읽다가 | 칸을 지웠고, 이후에는 매번 화면을 새로 읽어 입력 칸을 찾도록 바꿨다. 그 계정은 확인을 마친 뒤 삭제했다. |
| 웹에서 화면 밖에 있던 저장 버튼을 눌러 수정이 저장되지 않았다. | AI, 저장 후 화면을 읽다가 | 스크롤한 뒤 다시 저장했다. |
