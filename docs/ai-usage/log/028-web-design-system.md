# 2026-10-31 · 웹 디자인 토큰과 핵심 컴포넌트 5종 구현 (#46)

> 요약: 웹 MVP 여섯 번째 단계로 디자인 시스템 문서의 시멘틱 토큰과 핵심 컴포넌트 5종(Button, Card, PasswordField, EntropyGauge, BurnTimerBadge)을 웹 코드로 옮겼다. 외부 의존성 추가는 사람이 승인했다. 독립 코드 리뷰가 평문 비밀번호가 브라우저 입력 기록과 Edge 기본 보기 버튼으로 샐 수 있는 경로를 찾아 모두 반영했다.

## 사용 도구

- 도구: Claude Code (Claude Opus 5.5), Vitest, Testing Library
- 플러그인/스킬: `superpowers:test-driven-development`, 독립 코드 리뷰 서브에이전트, `issue-worktree:commit-rules`, `project-docs:ai-usage`

## 요청

- 이전 단계 병합 뒤 다음 계획을 확인하고, 디자인 시스템 단계의 의존성 추가를 승인했다.

## AI 산출물

- 토큰: 라이트·다크 CSS 변수와 Tailwind v4 `@theme inline` 연결, 기본 다크, 테마별 `color-scheme`.
- 컴포넌트: 변형·크기·로딩을 갖춘 버튼, 누를 수 있으면 button으로 그리는 카드, 10초 뒤 다시 가리는 비밀번호 필드, GEN-001 경계(60·80점)를 따르는 강도 게이지, 0초에 한 번 알리는 소각 배지.
- 의존성: clsx, tailwind-merge, lucide-react. Radix는 쓰는 컴포넌트가 없어 넣지 않았다.
- 문서: 디자인 시스템 3.1(웹 토큰 연결 방식, 시스템 글꼴 사용), 5.3(복사 콜백은 요청만 하고 클립보드 쓰기·소각은 받는 쪽이 맡음).

## 사람의 판단

- 클래스 병합·아이콘 의존성 추가를 승인했다.

## 검증

- `npm run check`(테스트 172건) 통과.
- 독립 코드 리뷰: 높음 0건, 중간 3건, 낮음 6건. 카드 안에 버튼을 둘 수 없는 제약은 문서로 남기고 나머지는 코드로 고쳤다. 고치기 전 새 테스트가 실패하는 것을 먼저 확인했다.

## 검증하지 못한 것

1. 실제 브라우저에서의 모양과 다크·라이트 대비는 로그인 화면 단계에서 확인한다.
2. Edge 기본 보기 버튼 숨김과 브라우저 입력 기록 제외는 jsdom으로 확인할 수 없다.

## AI의 오류와 정정

1. 평문 표시 중에도 자동완성이 켜져 있어, 그 상태로 제출하면 비밀번호가 브라우저 입력 기록에 남을 수 있었다. 평문 표시 중에는 자동완성을 끄고 맞춤법 검사 같은 보안 속성을 호출하는 쪽이 덮어쓰지 못하게 했다.
2. Edge가 그리는 기본 보기 버튼이 10초 뒤 다시 가리기를 우회했다. CSS로 숨겼다.
3. 값이 바깥에서 바뀌어도 다시 가리기 타이머가 재시작되지 않았고, 복사 콜백 없이도 복사 버튼이 그려졌으며, 소각 배지가 숫자가 아닌 시간을 그대로 표시했다. 각각 고쳤다.
4. Vitest globals가 꺼져 있어 테스트 사이에 화면이 정리되지 않았다. 테스트 준비 파일에 정리를 추가했다.
