# AI 활용 기록

> **요약** 이 프로젝트를 만들며 AI와 함께 한 작업을 작업 단위로 기록한다. 외부 제출과 평가의 근거 자료로 쓴다.

---

## 기록 원칙

| 원칙 | 내용 |
| :--- | :--- |
| 사실만 쓴다 | 실제로 있었던 대화, 결정, 오류, 검증 결과만 쓴다. 하지 않은 검증은 "하지 않음"이라고 쓴다. |
| 사람과 AI를 나눈다 | 제안과 코드는 "AI 산출물", 채택·수정·거부와 결정은 "사람의 판단"에 쓴다. |
| 추가만 한다 | 이미 쓴 항목의 문장은 고치지 않는다. 정정이 필요하면 새 항목을 쓴다. |
| 오류를 숨기지 않는다 | AI가 잘못 제안했거나 만든 결함과, 그것을 바로잡은 과정을 쓴다. |

---

## 구성

| 문서 | 내용 |
| :--- | :--- |
| [`log/`](log/README.md) | 작업 단위별 기록(`001-<슬러그>.md`, `002-<슬러그>.md` …)과 목록 표 |
| [`REPORT.md`](REPORT.md) | `log/`의 사실을 모은 집계 보고서. 요청이 있을 때 갱신한다. |

---

## 항목 쓰기

1. 기록 절차는 `project-docs:ai-usage` 스킬을 따른다.
2. 새 항목은 [`templates/ai-log.md`](../templates/ai-log.md)를 복사해 쓴다. 기존 항목은 템플릿에 맞춰 고치지 않는다.
3. 번호는 `log/` 안 최대 번호 + 1이다. 번호는 재사용하지 않는다. 다른 기기에서 같은 번호를 쓸 수 있으니 PR을 열기 직전에 `origin/main`의 번호를 다시 확인한다.
