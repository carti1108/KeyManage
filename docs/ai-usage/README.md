# KeyManage AI 활용 기록 (AI Usage)

이 디렉터리는 `KeyManage` 프로젝트를 개발하면서 AI와 협업한 모든 기록을 투명하게 보존하는 공간입니다. 외부 제출 및 부트캠프 평가의 근거 자료로 활용됩니다.

---

## 기록 원칙

1. **사실에 기반한 기록 (No Hallucination)**: 실제로 일어난 대화, 결정, 오류, 검증 결과만 작성합니다.
2. **역할 분리**: 제안과 코드는 "AI 산출물", 채택·수정·거부와 의사결정은 "사람의 판단"으로 엄격히 구분합니다.
3. **추가 전용 (Append-only)**: 이미 기록된 로그의 단어나 문장은 수정하지 않으며, 정정이 필요할 경우 새 로그를 발행합니다.
4. **오류와 정정의 투명한 공개**: AI가 잘못 제안했거나 발생시킨 버그, 이를 사람이 바로잡은 과정을 숨김없이 기록합니다.

---

## 디렉터리 구성

* [`log/`](log/README.md): 작업 단위별 상세 기록 (`001-slug.md`, `002-slug.md` ...)
* [`REPORT.md`](REPORT.md): `log/`의 사실들을 바탕으로 종합 집계한 최종 보고서

## 항목 틀

새 항목은 [`templates/ai-log.md`](../templates/ai-log.md)를 복사해 쓴다. 기존 항목은 템플릿에 맞춰 고치지 않는다.
