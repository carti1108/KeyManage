# KeyManage AI 활용 집계 보고서

> **요약** 2026-10-27부터 11-01까지 6일 동안 쌓인 AI 활용 로그 44건(001~044)을 모았다. 사람이 방향과 보안 경계를 정했고, AI가 설계 초안·구현·테스트·리뷰를 맡았다. 독립 리뷰 서브에이전트는 27건에서 썼고, 30건의 로그에 AI 오류와 정정 과정이 남아 있다. 서술마다 근거 로그 번호를 단다.

## 1. 프로젝트 개요

| 항목 | 내용 |
| :--- | :--- |

| 구성 | Kotlin/Spring Boot 포트-어댑터 백엔드, 웹(데스크톱 Tauri 포함), Apple 클라이언트 |

| 사용 도구 | Claude Code 33건(007~024, 027, 028, 030~036, 038, 040~044), Antigravity(Gemini) 11건(001~006, 025, 026, 029, 037, 039) |

## 4. AI의 오류와 정정

30건의 로그에 "AI의 오류와 정정" 절이 있다. 나머지 14건(002, 004~007, 009~011, 013, 014, 017, 029, 037, 039)에는 그 절이 없다. 절이 없다는 것은 오류가 없었다는 기록이 아니다.

| 유형 | 대표 사례 | 로그 |
| :--- | :--- | :--- |
| 보안 경계 결함 | 인증 필터가 원본 URI로 판단해 `;x=1`, `//`, `..;`로 우회됨 | 016 |
| 보안 경계 결함 | CSP가 모든 HTTPS와 localhost를 허용해 영지식 구조를 무력화 | 021 |
| 보안 경계 결함 | 서버 주소 검사가 `*`를 통과시켜 CSP에 와일드카드가 들어갈 수 있음 | 023 |
| 보안 경계 결함 | 잠금·로그아웃이 진행 중 작업을 끊지 못해 비밀번호 없이 볼트가 다시 열림 | 027 |
| 보안 경계 결함 | KDF 변경 시 되돌림 기준을 지워, 서버가 salt만 바꿔도 감지를 피할 수 있었음 | 038 |
| 데이터 손실 | 같은 초나 앞선 시계의 병합에서 수정이 사라짐 | 024 |
| 데이터 손실 | 저장 오류 후 화면이 상태를 다시 읽지 않아 대기 변경을 덮어씀 | 036 |
| 테스트 공백 | 구현 없이도 통과하는 테스트, 의도한 경로를 확인하지 못한 테스트 | 023, 031, 033, 035, 038 |
| 절차 위반 | 테스트보다 구현을 먼저 작성 | 023, 038 |
| 절차 위반 | 독립 리뷰를 임의로 생략하려 함 | 025 |
| 절차 위반 | 정책 수정을 사용자 확인 없이 진행 | 038 |
| 수정이 새 결함을 만듦 | 리뷰 반영 수정이 다른 결함을 연달아 만듦 | 036, 038 |
| 사실 오류 | 문자 풀 크기 계산 오류, 라이선스 오안내, 코드에 없는 타입을 명세에 기재 | 008, 038, 043 |
| 문서 의미 변경 | 정리 중 정책 규칙의 범위를 좁히거나 새 문구를 넣음 | 040, 042, 043, 044 |

누가 오류를 찾았는지 로그에 명시된 사례는 아래와 같다. 나머지는 적발 주체가 따로 적혀 있지 않다.

1. **독립 리뷰가 적발:** 015(필요한 정리 코드 삭제), 019(AAD 근거 불완전), 027(잠금 중 작업 미중단, 두 리뷰가 지적).
2. **테스트가 적발:** 012(필드 누락이 "첫 저장"으로 처리됨).
3. **사람이 적발:** 031(Chrome 저장 제안), 038(정책 무단 수정), 042(위계 없는 초안).
