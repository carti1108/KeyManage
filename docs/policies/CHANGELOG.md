# 정책 변경 이력 (Changelog)

- **2026-10-31**: `VLT-001` 저장 실패(네트워크·시간 초과·5xx) 시 동기화 대기로 두고 재연결·30초·잠금 해제 때 재전송, 잠금·세션 만료에도 대기 내용 보존, 대기 중 로그아웃 확인 문구 추가 (ADR-0018 기기 저장은 후속).
- **2026-10-31**: `COM-001` 아이디 등 볼트 값 복사에도 적용, 웹 브라우저 예외(백그라운드 탭은 돌아오거나 누를 때 비움, 읽기 권한 없이 비움)와 복사 실패·비우지 못함 문구 추가, 안내 문구를 "복사된 내용"으로 변경.
- **2026-10-31**: `GEN-001` 이어지는 숫자(123, 987 등) 안내 추가. 점수와 경고 기준은 그대로.
- **2026-10-31**: `VLT-001` 항목 서비스 이름 필수, 삭제 확인과 문구 추가.
- **2026-10-31**: `SEC-002`·`SEC-003`·`COM-001` 화면 오류 문구(이메일 형식, 쓸 수 없는 문자, 빈 볼트 저장 실패, 예상하지 못한 오류) 추가.
- **2026-10-31**: `SEC-002` 가입 시 마스터 비밀번호 최소 12자(클라이언트 검사)와 확인 입력, 서버 연결 실패 문구 추가.
- **2026-10-31**: `SEC-003` 가입 직후·볼트 없는 계정 로그인 시 빈 볼트 저장, 잠긴 동안 메모리에 남기는 값, 자동 잠금 시간 기준(마지막 조작부터) 추가.
- **2026-10-29**: `VLT-001` 삭제 항목 내용 제거, 모르는 필드 보존·높은 스키마 버전 읽기 전용, revision 되돌림 경고 추가, 네트워크 타임아웃 5초를 요청 제한 시간 30초로 변경.
- **2026-10-29**: `SEC-002` 클라이언트가 받는 반복 횟수 상한 10,000,000 추가.
- **2026-10-28**: `SEC-003` (잠금 해제 및 자동 잠금 정책) 신규 등록, `COM-001`에 앱 잠금 시 클립보드 즉시 비움 추가.
- **2026-10-28**: `SEC-002` (계정 인증 및 세션 정책) 신규 등록, `SEC-001` 반복 횟수 600,000회·HKDF 키 분리 반영 (ADR-0008).
- **2026-10-28**: `VLT-001` 충돌 해결을 Last-Write-Wins에서 낙관적 잠금(`revision`)과 클라이언트 항목 병합으로 변경, 충돌 문구·용량 측정 기준 추가 (ADR-0006).
- **2026-10-28**: `GEN-001` 점수 공식·문자군 크기·거부 샘플링·사용자 문구 확정, 적용 범위를 클라이언트 전용으로 변경 (ADR-0005).
- **2026-10-27**: `VLT-001` (크로스 플랫폼 볼트 동기화 및 충돌 해결 정책) 신규 등록.
- **2026-10-27**: 정책 SSOT 초기 체계 구축 및 초기 핵심 정책 등록 (`SEC-001`, `GEN-001`, `COM-001`).
