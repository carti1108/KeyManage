# 정책 변경 이력 (Changelog)

- **2026-11-02**: `SEC-005` 신설. 마스터 비밀번호와 확인 문구 `계정 삭제`로 확인한 뒤 서버가 계정·볼트·세션을 즉시 지우고, 클라이언트는 기기 기록을 지우고 모든 창을 로그아웃 (ADR-0024).
- **2026-11-02**: `SEC-003` 규칙 11의 비밀번호 바뀜 판정을 기기 볼트를 열지 못한 경우(새 비밀번호 입력)까지 넓히고, 서버에서 계정이 사라진 경우도 같은 안내임을 명시.
- **2026-11-02**: `SEC-002` 마스터 비밀번호가 바뀌면 이전 세션 모두 무효. `SEC-004` 교체와 겹쳐 발급된 세션도 무효, 새 토큰 발급 실패 시 세션 만료 응답, 같은 기기의 다른 창·탭 포함. `VLT-004` 반복 횟수 범위 근거를 SEC-001·SEC-002로 정정.
- **2026-11-02**: `SEC-004` 신설. 현재 비밀번호를 확인한 뒤 클라이언트가 새 키로 볼트를 다시 암호화하고, 서버가 KDF 값·인증 해시·볼트를 한 번에 교체한 뒤 다른 기기 세션을 모두 끝냄 (ADR-0023).
- **2026-11-02**: `VLT-004` 복원 규칙 변경. 병합 대신 백업에 있던 항목을 백업 시점 내용으로 되돌림(백업 뒤 수정·삭제를 되돌리고 수정 시각은 복원 시각). 백업 뒤 새로 만든 항목은 남기고, 복원 전 안내 추가.
- **2026-11-01**: `VLT-004` 신설. 볼트를 내보낸 시점의 마스터 비밀번호로 잠근 백업 파일로 내보내고, 복원은 지금 볼트에 병합. 파일에 계정 정보를 넣지 않고 처리는 클라이언트 안에서만 함 (ADR-0022).
- **2026-11-01**: `SEC-001` 마스터 비밀번호 입력 문구의 용어를 "마스터 키"에서 "마스터 비밀번호"로 맞추고, 가입 화면에서 잃어버리면 복구할 수 없다는 안내를 보이는 것으로 명시.
- **2026-11-01**: `SEC-003` 자동 잠금 시간 설정은 기기마다 저장하고 서버·다른 기기와 동기화하지 않음. 저장값이 없거나 선택지가 아니면 기본 5분, 바꾸면 그때부터 새 시간으로 잼, 웹은 열린 다른 탭에도 바로 반영. 로그아웃해도 설정은 남음.
- **2026-11-01**: `SEC-003` 웹 여러 탭 규칙 보완. 다른 계정으로 로그인하면 이전 계정의 모든 탭을 로그아웃하고, 숨겨진 탭의 자동 잠금 시간 초과와 다시 보이거나 첫 조작에서 발견한 시간 초과는 그 탭만 잠금 (#65).
- **2026-11-01**: `SEC-003` 웹 적용 범위에 여러 탭의 잠금 전파 범위 추가. 잠금 버튼, 화면을 보는 중의 자동 잠금 시간 초과, 로그아웃은 같은 계정의 모든 탭에 적용하고, 새로고침·탭 닫기·떠남·동결과 '즉시' 설정의 숨김은 그 탭만 잠금 (#65).
- **2026-11-01**: 정책 10개(`SEC-001`~`003`, `GEN-001`, `VLT-001`~`003`, `COM-001`~`002`)에 새 템플릿 적용. 규칙·값·문구·검증 방법을 제목·표·번호 목록으로 나누고, 이력은 접어 둠. `COM-001` 제목을 "클립보드 자동 비우기"로 바꾸고 용어를 "비운다"로 통일. `VLT-001` 관련에서 백엔드 ADR-0003 제외. 동작 변경 없음 (#70).
- **2026-11-01**: `COM-001`에서 오류 안내(크래시 방지, 예상하지 못한 오류 문구)를 `COM-002`로 나눔. `COM-001`의 네트워크 타임아웃 5초는 `VLT-001` 요청 제한 시간 30초와 어긋나 지우고, `COM-002`가 `VLT-001`의 값을 따르게 함 (#70).
- **2026-11-01**: `VLT-001`에서 오프라인 동기화 대기를 `VLT-002`로, 기기 볼트 보존을 `VLT-003`으로 나눔. `VLT-001`~`003`·`SEC-003` 규칙을 번호 목록으로 다시 쓰고, 플랫폼 구현 세부(IndexedDB, 탭 하나 전제, 토큰 보관 방식, Keychain)는 각 플랫폼 문서로 옮김. 동작 변경 없음 (#69).
- **2026-11-01**: `VLT-001`·`SEC-003` 오프라인 대기·기기 저장·재시작 뒤 잠금 화면 규칙을 모든 클라이언트 공통으로 정리. 웹 특수 사항(IndexedDB, 탭 하나 전제, 탭 떠남 확인, 토큰을 기기에 두지 않음)만 구분하고 Apple 미구현은 #68로 표시.
- **2026-11-01**: `SEC-003` 세션 없이 열 때 로그인하지 못한 실제 사유 표시. `VLT-001` 시작 때 읽지 못한 기기 기록을 로그인 뒤 다시 읽어 대기 내용 병합. 근거를 ADR-0020으로 갱신.
- **2026-11-01**: `VLT-001` 웹 기기 저장 보완(KDF 변경 시 되돌림 검사 유지, 다른 계정 인증 시 이전 기록 삭제, 저장 실패 경고 유지, 로그아웃 기록 삭제 실패 문구, 탭 하나 전제).
- **2026-11-01**: `SEC-003` 웹 재시작 뒤 기기 기록으로 잠금 화면, 세션 없는 잠금 해제·비밀번호 재입력, 비밀번호 바뀜 감지와 문구 추가. `VLT-001` 웹 기기 저장(한 계정, 삭제·폐기 시점, 저장 실패 문구), 떠남 확인 범위 조정 (ADR-0019).
- **2026-10-31**: `VLT-001` 저장 실패(네트워크·시간 초과·5xx·429·응답 형식 오류) 시 동기화 대기로 두고 재연결·30초·잠금 해제 때 재전송, 잠금·세션 만료에도 대기 내용 보존, 대기 중 로그아웃 확인 문구 추가 (ADR-0018 기기 저장은 후속).
- **2026-10-31**: `COM-001` 아이디 등 볼트 값 복사에도 적용, 웹 브라우저 예외(백그라운드 탭은 돌아오거나 누를 때 비움, 읽기 권한 없이 비움)와 복사 실패·비우지 못함 문구 추가, 안내 문구를 "복사된 내용"으로 변경.
- **2026-10-31**: `GEN-001` 이어지는 숫자(123, 987 등) 안내 추가. 점수와 경고 기준은 그대로.
- **2026-10-31**: `VLT-001` 항목 서비스 이름 필수, 삭제 확인과 문구 추가.
- **2026-10-31**: `SEC-002`·`SEC-003`·`COM-001` 화면 오류 문구(이메일 형식, 쓸 수 없는 문자, 빈 볼트 저장 실패, 예상하지 못한 오류) 추가.
- **2026-10-31**: `SEC-002` 가입 시 마스터 비밀번호 최소 12자(클라이언트 검사)와 확인 입력, 서버 연결 실패 문구 추가.
- **2026-10-31**: `SEC-003` 가입 직후·볼트 없는 계정 로그인 시 빈 볼트 저장, 잠긴 동안 메모리에 남기는 값, 자동 잠금 시간 기준(마지막 조작부터) 추가.
- **2026-10-29**: `VLT-001` 삭제 항목 내용 제거, 모르는 필드 보존·높은 스키마 버전 읽기 전용, revision 되돌림 경고 추가, 네트워크 타임아웃 5초를 요청 제한 시간 30초로 변경.
- **2026-10-29**: `SEC-002` 클라이언트가 받는 반복 횟수 상한 10,000,000 추가.
- **2026-10-28**: `SEC-003` (잠금 해제 및 자동 잠금 정책) 신규 등록, `COM-001`에 앱 잠금 시 클립보드 즉시 비움 추가.
- **2026-10-28**: `SEC-002` (계정 인증 및 세션 정책) 신규 등록, `SEC-001` 반복 횟수 600,000회·HKDF 키 분리 반영 (ADR-0008).
