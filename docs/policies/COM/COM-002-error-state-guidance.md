# COM-002 오류 상태 안내 정책
- 상태: 확정
- 규칙:
  1. 마스터 키 불일치나 네트워크 단절이 일어나도 앱은 크래시되지 않는다. 안전한 오류 상태로 바꾸고 사용자에게 안내한다.
  2. 정책에 정한 문구가 없는 예상하지 못한 오류는 내부 메시지를 드러내지 않고 공통 문구를 보인다.
  3. 네트워크 요청 제한 시간은 VLT-001의 값을 따른다.
- 값: 해당 없음
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 오류 처리와 네트워크 호출기
- 예외: 없음
- 사용자 문구:
  - 예상하지 못한 오류: 본문 "알 수 없는 오류가 발생했습니다. 잠시 후 다시 시도해 주세요."
- 근거: docs/adr/ADR-0001-zero-knowledge-security-architecture.md
- 검증 방법: 복호화 실패 시 예외 전환 테스트; 예상하지 못한 오류가 내부 메시지 대신 공통 문구로 바뀌는지 확인
- 비고: 관련: COM-001, SEC-002, VLT-001
- 이력: 2026-11-01 COM-001에서 오류 안내를 나눠 등록. 분리 전 이력은 COM-001에 있다.
