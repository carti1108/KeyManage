# COM-002 오류 상태 안내 정책
- 상태: 확정
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 오류 처리와 네트워크 호출기

> **요약** 오류가 나도 앱은 멈추지 않고, 안전한 오류 상태를 사용자에게 안내한다.

## 규칙

1. 마스터 키 불일치나 네트워크 단절이 일어나도, 앱은 크래시되지 않는다. 클라이언트는 안전한 오류 상태로 바꾸고 사용자에게 안내한다.
2. 정책에 정한 문구가 없는 예상하지 못한 오류이면, 클라이언트는 내부 메시지를 드러내지 않고 공통 문구를 보인다.
3. 네트워크 요청 제한 시간은 VLT-001의 값을 따른다.

## 값

해당 없음

## 예외

없음

## 사용자 문구

| 상황 | 제목 | 본문 | 버튼 |
| :--- | :--- | :--- | :--- |
| 예상하지 못한 오류 | | 알 수 없는 오류가 발생했습니다. 잠시 후 다시 시도해 주세요. | |

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 단위 테스트 | 복호화 실패 시 예외 전환; 예상하지 못한 오류가 내부 메시지 대신 공통 문구로 바뀜 |
