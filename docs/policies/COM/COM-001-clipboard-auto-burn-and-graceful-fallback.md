# COM-001 클립보드 30초 자동 소각 및 오류 방어 정책
- 상태: 확정
- 규칙: 클라이언트에서 비밀번호를 클립보드로 복사한 경우, 메모리 탈취를 방지하기 위해 30초 경과 즉시 클립보드 내용을 자동으로 소각(빈 값으로 덮어쓰기)해야 한다. 또한 마스터 키 불일치나 네트워크 단절 시 앱이 크래시되지 않고 안전한 에러 상태를 사용자에게 안내해야 한다.
- 값: 클립보드 유효 시간 정확히 30초; 네트워크 타임아웃 5초
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 클립보드 관리자 및 네트워크 호출기
- 예외: 사용자가 30초 이내에 다른 텍스트를 복사한 경우 기존 타이머는 무효화된다. 앱이 잠기면(SEC-003) 30초를 기다리지 않고 즉시 비운다
- 사용자 문구: 제목 "클립보드 보안 소각" / 본문 "보안을 위해 복사된 비밀번호가 30초 후 클립보드에서 자동 삭제됩니다."; 그 밖의 예상하지 못한 오류 본문 "알 수 없는 오류가 발생했습니다. 잠시 후 다시 시도해 주세요."
- 근거: docs/adr/ADR-0001-zero-knowledge-security-architecture.md
- 검증 방법: 클립보드 타이머 모의 테스트 및 복호화 실패 시 예외 전환 테스트
- 비고: ADR-0001, SEC-003
- 이력: 2026-10-27 초기 등록; 2026-10-28 앱 잠금 시 즉시 비움 추가 (SEC-003); 2026-10-31 예상하지 못한 오류 문구 추가
