# COM-001 클립보드 30초 자동 소각 및 오류 방어 정책
- 상태: 확정
- 규칙: 클라이언트에서 비밀번호(또는 아이디 등 볼트 값)를 클립보드로 복사한 경우, 메모리 탈취를 방지하기 위해 30초 경과 즉시 클립보드 내용을 자동으로 소각(빈 값으로 덮어쓰기)해야 한다. 또한 마스터 키 불일치나 네트워크 단절 시 앱이 크래시되지 않고 안전한 에러 상태를 사용자에게 안내해야 한다.
- 값: 클립보드 유효 시간 정확히 30초; 네트워크 타임아웃 5초
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 클립보드 관리자 및 네트워크 호출기
- 예외: 사용자가 30초 이내에 다른 텍스트를 복사한 경우 기존 타이머는 무효화된다. 앱이 잠기면(SEC-003) 30초를 기다리지 않고 즉시 비운다. 웹 브라우저는 탭이 활성 상태일 때만 클립보드를 쓸 수 있어, 30초가 됐을 때 비우지 못하면 탭으로 돌아오거나 화면을 누를 때 다시 비우고, 비우지 못했다는 안내와 직접 비우는 버튼을 보인다. 웹은 클립보드 읽기 권한을 요청하지 않으므로, 복사한 뒤 비울 때까지(비우지 못한 채 기다린 시간 포함) 사용자가 앱 밖에서 직접 복사한 내용도 비울 수 있다. 페이지를 닫거나 탭이 동결될 때는 비우지 못할 수 있다
- 사용자 문구: 제목 "클립보드 보안 소각" / 본문 "보안을 위해 복사된 내용이 30초 후 클립보드에서 자동 삭제됩니다."; 비우지 못함(웹) 본문 "클립보드를 아직 비우지 못했습니다. 이 화면을 누르면 다시 비웁니다." / 버튼 "지금 비우기"; 그 밖의 예상하지 못한 오류 본문 "알 수 없는 오류가 발생했습니다. 잠시 후 다시 시도해 주세요."; 복사 실패 본문 "클립보드에 복사하지 못했습니다."
- 근거: docs/adr/ADR-0001-zero-knowledge-security-architecture.md
- 검증 방법: 클립보드 타이머 모의 테스트 및 복호화 실패 시 예외 전환 테스트
- 비고: ADR-0001, SEC-003
- 이력: 2026-10-27 초기 등록; 2026-10-28 앱 잠금 시 즉시 비움 추가 (SEC-003); 2026-10-31 예상하지 못한 오류 문구 추가; 2026-10-31 아이디 등 볼트 값 복사에도 적용, 웹 브라우저 예외와 복사 실패·비우지 못함 문구 추가, 안내 문구를 "복사된 내용"으로 변경
