# COM-001 클립보드 자동 비우기
- 상태: 확정
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 클립보드 관리자

> **요약** 볼트 값을 복사하면 30초 뒤 클립보드를 비운다. 앱이 잠기면 즉시 비운다. 메모리 탈취를 막기 위해서다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 비운다 | 클립보드 내용을 빈 값으로 덮어쓴다. 화면 문구의 "소각"·"삭제"와 같은 동작이다. |
| 볼트 값 | 볼트 항목의 비밀번호, 아이디 등 사용자가 저장한 값 |

## 규칙

1. 사용자가 볼트 값을 복사하면, 클라이언트는 30초가 지나는 즉시 클립보드를 비운다.
2. 30초가 되기 전에 사용자가 다른 텍스트를 복사하면, 클라이언트는 기존 타이머를 무효로 한다.
3. 앱이 잠기면(SEC-003), 클라이언트는 30초를 기다리지 않고 즉시 클립보드를 비운다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 클립보드 유효 시간 | 30초 | 정확히 30초 |

## 예외: 웹 브라우저

> **주의** 페이지를 닫거나 탭이 동결될 때는 클립보드를 비우지 못할 수 있다.

1. 브라우저는 탭이 활성 상태일 때만 클립보드를 쓸 수 있다.
2. 30초가 됐을 때 비우지 못하면, 클라이언트는 사용자가 탭으로 돌아오거나 화면을 누를 때 다시 비운다.
3. 비우지 못하면, 클라이언트는 비우지 못했다는 안내와 직접 비우는 버튼을 보인다.
4. 웹은 클립보드 읽기 권한을 요청하지 않는다. 그래서 복사한 뒤 비울 때까지(비우지 못한 채 기다린 시간 포함) 사용자가 앱 밖에서 직접 복사한 내용도 비울 수 있다.

## 사용자 문구

| 상황 | 제목 | 본문 | 버튼 |
| :--- | :--- | :--- | :--- |
| 복사 직후 | 클립보드 보안 소각 | 보안을 위해 복사된 내용이 30초 후 클립보드에서 자동 삭제됩니다. | |
| 비우지 못함(웹) | | 클립보드를 아직 비우지 못했습니다. 이 화면을 누르면 다시 비웁니다. | 지금 비우기 |
| 복사 실패 | | 클립보드에 복사하지 못했습니다. | |

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 클립보드 타이머 모의 테스트 | 30초 뒤 비움, 30초 전 다시 복사 시 타이머 교체, 잠금 시 즉시 비움 |
