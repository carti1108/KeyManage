# VLT-001 크로스 플랫폼 볼트 동기화 및 충돌 해결 정책
- 상태: 확정
- 규칙: 모든 플랫폼(iOS/macOS, Android, Web)은 동등한 권한으로 암호화된 볼트를 생성·수정·조회할 수 있어야 한다. 동기화는 앱 실행 시 및 볼트 데이터 변경 즉시 이벤트 기반으로 수행되며, 다중 기기 충돌 발생 시 최종 수정 시간(updatedAt) 기준 최신 데이터로 자동 덮어쓴다(Last-Write-Wins). 오프라인 상태에서는 로컬 볼트를 우선 사용하되 상단에 미동기화 경고를 노출해야 한다.
- 값: 볼트 최대 허용 용량 5MB 이하; 네트워크 타임아웃 5초; 충돌 기준 updatedAt 최신 우선
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web) 및 백엔드 볼트 컨트롤러/저장소
- 예외: 오프라인 모드에서는 서버 전송을 생략하고 로컬 저장소만 갱신하며, 네트워크 재연결 시 즉시 동기화를 시도한다
- 사용자 문구: 
  - 용량 초과: 제목 "저장 실패" / 본문 "볼트 허용 용량(5MB)을 초과했거나 데이터 규격이 올바르지 않습니다."
  - 오프라인 경고: 본문 "오프라인 상태입니다. 변경 사항이 서버에 동기화되지 않습니다."
- 근거: docs/vault-spec.md; docs/api-spec.md
- 검증 방법: 단위/통합 테스트 (동시 수정 시 updatedAt 최신 볼트 반영 검증, 오프라인 모드 전환 시 배너 노출 검증)
- 비고: SEC-001, ADR-0001, ADR-0003
- 이력: 2026-10-27 초기 등록
