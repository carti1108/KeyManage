# VLT-001 크로스 플랫폼 볼트 동기화 및 충돌 해결 정책
- 상태: 확정
- 규칙: 모든 플랫폼(iOS/macOS, Android, Web)은 동등한 권한으로 암호화된 볼트를 생성·수정·조회할 수 있어야 한다. 동기화는 앱 실행 시 및 볼트 데이터 변경 즉시 이벤트 기반으로 수행되며, 다중 기기 충돌은 낙관적 잠금으로 감지한다. 서버는 저장 성공 시 1씩 증가하는 `revision`을 발급하고, 클라이언트가 보낸 `expectedRevision`이 서버 값과 다르면 409로 거절한다. 거절받은 클라이언트는 최신 볼트를 받아 항목별 `updatedAt`(삭제는 `deletedAt`)이 최신인 쪽으로 자동 병합해 다시 저장하며, 최대 3회까지 재시도한다. 오프라인 상태에서는 로컬 볼트를 우선 사용하되 상단에 미동기화 경고를 노출해야 한다.
- 값: 볼트 최대 허용 용량 5MB(5,242,880바이트, 요청 페이로드 JSON 기준, 이 값과 같으면 허용); 네트워크 타임아웃 5초; revision은 정수이며 첫 저장 시 1, 볼트가 없을 때 기대값 0; 자동 병합 재시도 최대 3회; 항목 시간이 같으면 서버 쪽 우선
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web) 및 백엔드 볼트 컨트롤러/저장소
- 예외: 오프라인 모드에서는 서버 전송을 생략하고 로컬 저장소만 갱신하며, 네트워크 재연결 시 즉시 동기화를 시도한다. 재연결 시 서버 revision이 앞서 있으면 충돌 처리 절차를 따른다
- 사용자 문구: 
  - 용량 초과: 제목 "저장 실패" / 본문 "볼트 허용 용량(5MB)을 초과했거나 데이터 규격이 올바르지 않습니다."
  - 오프라인 경고: 본문 "오프라인 상태입니다. 변경 사항이 서버에 동기화되지 않습니다."
  - 동기화 충돌(자동 재시도 3회 모두 실패 시): 제목 "동기화 충돌" / 본문 "다른 기기의 변경 사항과 충돌했습니다. 잠시 후 다시 시도해 주세요."
- 근거: docs/vault-spec.md; docs/api-spec.md; docs/adr/ADR-0006-optimistic-locking-vault-sync.md
- 검증 방법: 단위 테스트(기대 revision 일치 시 저장 후 +1, 불일치 시 충돌 오류, 같은 revision으로 동시 2건 저장 시 1건만 성공, 용량 5,242,880바이트 허용·1바이트 초과 거절, 볼트 없을 때 기대값 0으로 첫 저장), 클라이언트 테스트(항목 병합과 삭제 표시, 오프라인 모드 전환 시 배너 노출)
- 비고: SEC-001, ADR-0001, ADR-0003, ADR-0006
- 이력: 2026-10-27 초기 등록; 2026-10-28 충돌 해결을 Last-Write-Wins에서 낙관적 잠금과 클라이언트 병합으로 변경 (ADR-0006)
