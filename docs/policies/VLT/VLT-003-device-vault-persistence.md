# VLT-003 기기 볼트 보존 정책
- 상태: 확정
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)

> **요약** 클라이언트는 한 계정의 암호화된 볼트와 동기화 상태를 기기에 둔다. 재시작 뒤에도 대기 내용과 되돌림 감지 기준을 이어 간다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 기기 기록 | 기기에 저장한 한 계정의 암호화된 볼트와 동기화 상태(기준 revision, 마지막으로 본 revision, 대기 표시) |

## 규칙

> **주의** 공용 기기에서 다른 계정의 기록이 남으면 안 된다. 다른 계정의 인증이 성공하면 이전 기록부터 지운다.

1. 클라이언트는 한 계정의 암호화된 볼트와 동기화 상태(기준 revision, 마지막으로 본 revision, 대기 표시)를 기기에 저장한다. 재시작 뒤에도 대기 내용과 되돌림 감지 기준을 이어 가기 위해서다.
2. 기기에는 한 계정만 둔다.
3. 다른 계정의 인증(로그인·가입)이 성공하면, 클라이언트는 그 계정의 볼트를 열기 전이라도 이전 계정의 기록을 지운다. 인증에 실패하면 지우지 않는다.
4. 로그아웃하면, 클라이언트는 기기 기록을 지운다.
5. 같은 이메일로 로그인할 때 서버 KDF 값이 저장한 값과 다르면, 클라이언트는 대기 내용을 버린다. 되돌림 검사는 그대로 하고, 기기 사본은 볼트를 연 뒤에야 바꾼다.
6. 앱을 열 때 기기 기록을 읽지 못했으면, 클라이언트는 로그인한 뒤 기기에 처음 쓰기 전에 다시 읽는다. 같은 계정의 대기 내용이 있으면 병합해 올린다.
7. 기기에 저장하지 못하면, 클라이언트는 다음 저장이 성공할 때까지 경고한다.
8. 로그아웃 때 기기 기록을 지우지 못하면, 클라이언트는 알린다.

## 값

| 항목 | 값 |
| :--- | :--- |
| 기기에 두는 계정 수 | 1 |
