# GEN-001 무작위 암호 생성 및 엔트로피 점수 산출 규칙
- 상태: 확정
- 규칙: 비밀번호 생성기는 암호학적으로 안전한 난수(CSPRNG)로 선택된 문자군 전체 풀에서 균등하게 뽑고, 선택된 문자군(대문자, 소문자, 숫자, 특수기호)이 하나라도 빠지면 버리고 다시 뽑는다(거부 샘플링). 엔트로피 감사기는 비밀번호에 실제로 들어 있는 문자군으로 풀 크기를 정해 `min(100, floor(길이 × log₂(풀 크기)))`점을 산출한다. 잘못된 생성 옵션은 생성을 차단하고, 낮은 점수는 경고만 하고 사용은 허용한다. 비밀번호 원문은 서버로 보내거나 로그에 남기지 않는다. 비밀번호에 이어지는 숫자가 있으면 점수와 별개로 안내한다. 점수와 경고 기준은 바꾸지 않는다.
- 값: 비밀번호 최소 길이 8자 이상, 최대 길이 64자 이하 (기본값 16자); 문자군 크기 대문자 26, 소문자 26, 숫자 10, 특수기호 26(`!@#$%^&*()_+-=[]{}|;:,.<>?`), 그 외 문자 7(하나라도 있으면 한 번만 더함); 길이는 유니코드 코드포인트 수; 점수 소수점 버림; 빈 문자열 0점; 안전 점수 60점 미만 취약(Danger), 60점 이상 80점 미만 보통(Warning), 80점 이상 안전(Secure); 이어지는 숫자는 3자리 이상, 한 방향으로 계속 1씩 오르거나 내리는 ASCII 숫자(예: 123, 456, 987, 3210). 방향이 바뀌거나(121) 9에서 0, 0에서 9로 넘어가면 끊긴 것으로 보고, 사이에 다른 문자가 끼어도 끊긴 것으로 본다
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 비밀번호 생성/진단 화면. 백엔드는 생성·진단을 수행하지 않는다(ADR-0005)
- 예외: 없음
- 사용자 문구: 제목 "취약한 비밀번호 경고" / 본문 "현재 비밀번호는 보안에 취약합니다. 80점 이상의 강력한 비밀번호로 재생성하세요."; 길이 오류 "비밀번호 길이는 최소 8자 이상 64자 이하이어야 합니다."; 문자군 없음 "최소 1개 이상의 문자 종류를 선택해야 합니다."; 이어지는 숫자 안내 "123처럼 이어지는 숫자가 들어 있어 추측하기 쉽습니다."
- 근거: docs/adr/ADR-0001-zero-knowledge-security-architecture.md, docs/adr/ADR-0005-client-only-password-generation-and-audit.md
- 검증 방법: 단위 테스트(길이 범위 8~64 경계값 검증, 4개 문자군 100% 포함 여부 1,000회 반복 검증) 및 플랫폼 공통 샘플(`123456` → 19점, `abc~~~~~` → 40점, 4개 문자군 12자 → 77점, 4개 문자군 16자 → 100점); 이어지는 숫자 샘플(`a123b`·`9876` 안내, `890`·`1a2b3`·`12`·`121` 안내 없음)
- 비고: ADR-0005
