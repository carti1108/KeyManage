# GEN-001 무작위 암호 생성 및 엔트로피 점수 산출 규칙
- 상태: 확정
- 규칙: 비밀번호 생성기는 암호학적으로 안전한 난수(CSPRNG)를 사용해 지정된 길이 내에서 선택된 모든 문자군(대문자, 소문자, 숫자, 특수기호)이 최소 1자 이상 포함되도록 보장해야 한다. 엔트로피 감사기는 길이와 문자 다양성을 기반으로 0점 이상 100점 이하의 안전도 점수를 산출한다.
- 값: 비밀번호 최소 길이 8자 이상, 최대 길이 64자 이하 (기본값 16자); 안전 점수 60점 미만 취약(Danger), 60점 이상 80점 미만 보통(Warning), 80점 이상 안전(Secure)
- 적용 범위: 백엔드 암호 엔진(`:domain`) 및 모든 클라이언트 비밀번호 생성/진단 화면
- 예외: 없음
- 사용자 문구: 제목 "취약한 비밀번호 경고" / 본문 "현재 비밀번호는 보안에 취약합니다. 80점 이상의 강력한 비밀번호로 재생성하세요."
- 근거: docs/adr/ADR-0002-hexagonal-multi-module-backend.md
- 검증 방법: 단위 테스트(길이 범위 8~64 경계값 검증, 4개 문자군 100% 포함 여부 1,000회 반복 검증)
- 비고: ADR-0002
- 이력: 2026-10-27 초기 등록
