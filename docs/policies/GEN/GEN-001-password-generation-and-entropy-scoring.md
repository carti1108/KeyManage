# GEN-001 무작위 암호 생성 및 엔트로피 점수 산출 규칙
- 상태: 확정
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 비밀번호 생성·진단 화면. 백엔드는 생성·진단을 하지 않는다(ADR-0005).

> **요약** 생성기는 안전한 난수로 선택한 문자군을 모두 넣어 만든다. 감사기는 길이와 문자군으로 0~100점을 매긴다. 낮은 점수는 경고만 한다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 문자군 | 대문자, 소문자, 숫자, 특수기호. 감사기는 그 외 문자도 한 문자군으로 센다. |
| 풀 크기 | 생성기: 사용자가 선택한 문자군 크기의 합. 감사기: 비밀번호에 실제로 들어 있는 문자군 크기의 합. |
| 이어지는 숫자 | 아래 '값'에 정의한 숫자 열 |

## 규칙

1. 생성기는 암호학적으로 안전한 난수(CSPRNG)로, 선택된 문자군 전체 풀에서 균등하게 뽑는다.
2. 선택된 문자군(대문자, 소문자, 숫자, 특수기호)이 하나라도 빠지면, 생성기는 버리고 다시 뽑는다(거부 샘플링).
3. 감사기는 비밀번호에 실제로 들어 있는 문자군으로 풀 크기를 정한다. 점수는 `min(100, floor(길이 × log₂(풀 크기)))`점이다.
4. 생성 옵션이 잘못되면, 클라이언트는 생성을 차단한다.
5. 점수가 낮으면, 클라이언트는 경고만 하고 사용은 허용한다.
6. 클라이언트는 비밀번호 원문을 서버로 보내거나 로그에 남기지 않는다.
7. 비밀번호에 이어지는 숫자가 있으면, 클라이언트는 점수와 별개로 안내한다. 이 안내는 점수와 경고 기준을 바꾸지 않는다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 비밀번호 길이 | 최소 8자, 최대 64자, 기본값 16자 | 8자 이상, 64자 이하. 유니코드 코드포인트 수로 센다. |
| 대문자 | 26 | |
| 소문자 | 26 | |
| 숫자 | 10 | |
| 특수기호 | 26 (`!@#$%^&*()_+-=[]{}\|;:,.<>?`) | <!-- 표 안이라 세로선 앞에 역슬래시를 붙였다. 실제 문자 26개에 역슬래시는 없다. --> |
| 그 외 문자 | 7 | 하나라도 있으면 한 번만 더한다 |
| 점수 | 0~100점 | 소수점 버림. 빈 문자열은 0점. |
| 취약(Danger) | 60점 미만 | |
| 보통(Warning) | 60점 이상 80점 미만 | |
| 안전(Secure) | 80점 이상 | |
| 이어지는 숫자 | 3자리 이상, 한 방향으로 계속 1씩 오르거나 내리는 ASCII 숫자(예: 123, 456, 987, 3210) | 방향이 바뀌거나(121) 9에서 0, 0에서 9로 넘어가면 끊긴 것으로 본다. 사이에 다른 문자가 끼어도 끊긴 것으로 본다. |

## 사용자 문구

| 상황 | 제목 | 본문 | 버튼 |
| :--- | :--- | :--- | :--- |
| 취약한 비밀번호 | 취약한 비밀번호 경고 | 현재 비밀번호는 보안에 취약합니다. 80점 이상의 강력한 비밀번호로 재생성하세요. | |
| 길이 오류 | | 비밀번호 길이는 최소 8자 이상 64자 이하이어야 합니다. | |
| 문자군 없음 | | 최소 1개 이상의 문자 종류를 선택해야 합니다. | |

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 단위 테스트 | 길이 8~64 경계값; 4개 문자군을 모두 포함하는지 1,000회 반복 |
| 플랫폼 공통 점수 샘플 | `123456` → 19점, `abc~~~~~` → 40점, 4개 문자군 12자 → 77점, 4개 문자군 16자 → 100점 |
| 이어지는 숫자 샘플 | `a123b`·`9876`은 안내함; `890`·`1a2b3`·`12`·`121`은 안내하지 않음 |
