# SEC-001 클라이언트 영지식 암복호화 규격
- 상태: 확정
- 규칙: 사용자의 마스터 키로부터 256비트 대칭키를 유도하고, 볼트 원문(JSON)을 암호화하여 서버에는 암호문만 전송해야 한다. 평문 비밀번호나 마스터 키는 네트워크를 타거나 서버 메모리에 올라가지 않는다. 마스터 키에서 암호화 키와 인증 해시를 HKDF로 분리하며, 인증 해시만 서버로 보낸다(SEC-002).
- 값: 키 유도 알고리즘 PBKDF2(HMAC-SHA256, 반복 횟수 600,000회), 계정 salt 16바이트; 키 분리 HKDF-SHA256(info "keymanage-enc"·"keymanage-auth"); 암호화 알고리즘 AES-256-GCM(초기화 벡터 IV 12바이트, 인증 태그 16바이트)
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 로컬 볼트 저장소 및 네트워크 전송 계층
- 예외: 없음
- 사용자 문구: 제목 "마스터 키 설정 필요" / 본문 "볼트를 열기 위한 마스터 키를 입력해주세요. 마스터 키를 분실하면 복구할 수 없습니다."
- 근거: docs/adr/ADR-0001-zero-knowledge-security-architecture.md; docs/adr/ADR-0008-auth-hash-and-server-session.md
- 검증 방법: 단위 테스트(올바른 마스터 키로만 복호화 성공, 임의 키 입력 시 복호화 실패 검증, 같은 마스터 키에서 만든 암호화 키와 인증 해시가 서로 다름)
- 비고: ADR-0001, ADR-0008
- 이력: 2026-10-27 초기 등록; 2026-10-28 반복 횟수 600,000회, 키 분리 구조 반영 (ADR-0008)
