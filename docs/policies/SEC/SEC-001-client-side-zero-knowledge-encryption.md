# SEC-001 클라이언트 영지식 암복호화 규격
- 상태: 확정
- 적용 범위: 모든 클라이언트(iOS/macOS, Android, Web)의 로컬 볼트 저장소와 네트워크 전송 계층

> **요약** 클라이언트가 마스터 키로 볼트를 암호화하고, 서버에는 암호문과 인증 해시만 보낸다.

## 규칙

> **주의** 평문 비밀번호나 마스터 키가 네트워크나 서버로 나가면 영지식 구조가 깨진다.

1. 클라이언트는 사용자의 마스터 키로부터 256비트 대칭키를 유도한다.
2. 클라이언트는 볼트 원문(JSON)을 암호화해 서버에는 암호문만 전송한다.
3. 평문 비밀번호나 마스터 키는 네트워크를 타거나 서버 메모리에 올라가지 않는다.
4. 클라이언트는 마스터 키에서 암호화 키와 인증 해시를 HKDF로 분리한다. 인증 해시만 서버로 보낸다(SEC-002).

## 값

| 항목 | 값 |
| :--- | :--- |
| 키 유도 | PBKDF2(HMAC-SHA256, 반복 횟수 600,000회) |
| 계정 salt | 16바이트 |
| 키 분리 | HKDF-SHA256(info "keymanage-enc"·"keymanage-auth") |
| 암호화 | AES-256-GCM(초기화 벡터 IV 12바이트, 인증 태그 16바이트) |
