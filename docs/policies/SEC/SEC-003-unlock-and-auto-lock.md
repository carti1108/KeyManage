# SEC-003 잠금 해제 및 자동 잠금 정책
- 상태: 확정
- 규칙: 잠금은 메모리의 암호화 키를 지우고 볼트 화면을 가리는 것이며, 로그아웃과 달리 세션 토큰은 유지해 잠금을 풀면 바로 동기화한다. 앱이 백그라운드에 있거나 조작이 없으면 설정한 시간 뒤 자동으로 잠그고, 백그라운드로 갈 때는 앱 전환 화면에 볼트 내용이 비치지 않도록 가림 화면을 씌운다. 잠금 해제는 마스터 비밀번호 또는 (켠 경우) 생체 인증으로 하며, 오프라인에서도 볼트 복호화 성공 여부로 확인한다. 잠기면 클립보드를 즉시 비운다. 기기에 생체 정보가 새로 등록되면 생체 해제를 무효화하고 마스터 비밀번호를 요구한다.
- 값: 자동 잠금 기본 5분(선택: 즉시·1분·5분·15분·1시간, "잠그지 않음"은 없음); 생체 인증 기본 꺼짐(가입 직후 켤지 묻는다); 생체 인증을 켜도 14일마다 한 번 마스터 비밀번호 요구; 생체 해제용 키는 이 기기 전용 저장소(iOS는 생체 인증으로 보호되는 Keychain, ThisDeviceOnly, iCloud 동기화·백업 제외)
- 적용 범위: iOS(생체 인증과 자동 잠금), 웹 브라우저(자동 잠금, 새로고침·탭 닫기 시 잠김), 데스크톱 앱(자동 잠금, Windows Hello는 데스크톱 패키징 단계), macOS·Android는 해당 클라이언트 구현 시
- 예외: 생체 인증이 등록되지 않은 기기는 마스터 비밀번호만 쓴다
- 사용자 문구:
  - 잠금 화면: 제목 "볼트가 잠겼습니다" / 버튼 "Face ID로 잠금 해제", "마스터 비밀번호 입력"
  - 비밀번호 오류: 본문 "마스터 비밀번호가 올바르지 않습니다."
- 근거: docs/adr/ADR-0010-client-composition-ios-and-shared-web.md; docs/vault-spec.md
- 검증 방법: 클라이언트 테스트(설정 시간 경과 후 잠기고 키가 메모리에서 지워짐, 백그라운드 진입 시 가림 화면, 잠금 시 클립보드 즉시 비움, 오프라인 잠금 해제, 생체 정보 변경 시 생체 해제 무효화, 14일 경과 시 마스터 비밀번호 요구)
- 비고: SEC-001, COM-001, ADR-0010
- 이력: 2026-10-28 초기 등록
