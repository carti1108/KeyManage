# SEC-003 잠금 해제 및 자동 잠금 정책
- 상태: 확정
- 적용 범위: iOS, macOS, 웹 브라우저, 데스크톱 앱 (Android는 해당 클라이언트를 구현할 때). 플랫폼별 범위는 아래 '적용 범위' 표를 본다.

> **요약** 잠금은 메모리의 키를 지우고 화면을 가린다. 세션 토큰은 남겨, 잠금을 풀면 바로 동기화한다. 조작이 없으면 설정한 시간 뒤 자동으로 잠근다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 잠금 | 메모리의 암호화 키를 지우고 볼트 화면을 가리는 것. 로그아웃과 달리 세션 토큰은 남긴다. |
| 세션 없이 열기 | 세션 토큰 없이 이 기기의 볼트만 복호화해 여는 것 |

## 규칙

> **주의** 잠긴 동안 메모리에 암호화 키·평문 볼트·인증 해시가 남으면 잠금이 의미가 없다.

1. 잠금은 메모리의 암호화 키를 지우고 볼트 화면을 가리는 것이다. 로그아웃과 달리 세션 토큰은 유지해, 잠금을 풀면 바로 동기화한다.
2. 앱이 백그라운드에 있거나 조작이 없으면, 클라이언트는 설정한 시간 뒤 자동으로 잠근다.
3. 백그라운드로 갈 때, 클라이언트는 앱 전환 화면에 볼트 내용이 비치지 않도록 가림 화면을 씌운다.
4. 잠금은 마스터 비밀번호 또는 (켠 경우) 생체 인증으로 푼다. 오프라인에서도 볼트 복호화 성공 여부로 확인한다.
5. 이 확인이 항상 가능하도록 모든 계정은 볼트를 가진다.
   - 가입 직후 빈 볼트를 저장한다.
   - 볼트가 없는 계정으로 로그인하면(가입 직후 저장이 실패한 경우 등) 볼트를 여는 화면으로 넘어가기 전에 빈 볼트를 저장한다.
6. 잠긴 동안 메모리에는 이메일, KDF 값(salt·반복 횟수), 세션 토큰, 암호화된 볼트만 남긴다. 암호화 키·평문 볼트·인증 해시는 남기지 않는다.
7. 잠기면, 클라이언트는 클립보드를 즉시 비운다.
8. 기기에 생체 정보가 새로 등록되면, 클라이언트는 생체 해제를 무효화하고 마스터 비밀번호를 요구한다.
9. 앱을 다시 열면, 클라이언트는 기기에 저장한 계정(VLT-003)으로 잠금 화면을 연다.
10. 세션 토큰이 없으면(토큰을 기기에 둘지는 플랫폼마다 정한다):
    - 온라인이면 잠금 해제 때 만든 인증 해시로 바로 로그인하고, 응답을 받는 즉시 인증 해시를 지운다.
    - 오프라인이거나 서버에 닿지 못하면 인증 해시를 바로 지우고 볼트만 연다. 동기화하려면 마스터 비밀번호를 다시 입력받아 로그인한다.
    - 인증 해시는 이 요청 밖에서 메모리에 남기지 않는다.
11. 로그인 전에 서버가 준 KDF 값이 기기에 저장한 값과 다르거나 로그인이 인증 실패로 거절되면, 클라이언트는 마스터 비밀번호가 바뀐 것으로 보고 로그인 화면으로 보낸다. 기기의 볼트를 입력한 비밀번호로 열지 못했을 때도 서버에 닿으면 KDF 값을 확인해 같은 판정을 한다(새 비밀번호를 입력한 경우). 서버에서 계정이 사라진 경우도 KDF 값이 달라 같은 안내를 받는다.
12. 그 밖의 이유로 로그인하지 못하면, 클라이언트는 볼트를 세션 없이 연다. 다시 입력할 때는 실제 사유(연결 실패, 서버 오류, 거절)를 보여 준다.

## 값

| 항목 | 값 | 경계·비고 |
| :--- | :--- | :--- |
| 자동 잠금 | 기본 5분 | 선택지는 즉시·1분·5분·15분·1시간이며 "잠그지 않음"은 없다. 마지막 조작부터 잰다. "즉시"는 백그라운드로 가는 순간 잠근다. 설정은 기기마다 저장하고 서버·다른 기기와 동기화하지 않으며, 로그아웃·계정 전환 뒤에도 남는다. 저장값이 없거나 선택지가 아니면 기본값을 쓴다. 바꾸면 그때부터 새 시간으로 잰다. |
| 생체 인증 | 기본 꺼짐 | 가입 직후 켤지 묻는다. |
| 마스터 비밀번호 재요구 | 14일마다 한 번 | 생체 인증을 켜도 요구한다. |
| 생체 해제용 키 | 이 기기 전용 저장소 | 생체 인증으로 보호하고 클라우드 동기화·백업에서 뺀다. |

## 적용 범위

| 플랫폼 | 범위 |
| :--- | :--- |
| iOS | 생체 인증과 자동 잠금 |
| 웹 브라우저 | 자동 잠금. 새로고침·탭 닫기·페이지 떠남·탭 동결 때 바로 잠근다. 잠금 버튼, 화면을 보는 중의 자동 잠금 시간 초과, 로그아웃은 같은 계정의 모든 탭에 적용한다. 새로고침·탭 닫기·떠남·동결, '즉시' 설정에서 탭이 숨겨질 때는 그 탭만 잠근다. 다른 계정으로 로그인하면 이전 계정으로 열린 모든 탭을 로그아웃한다. 숨겨진 탭에서 자동 잠금 시간이 다 되었거나, 다시 보이거나 처음 조작할 때 시간이 지난 것을 알게 되면 그 탭만 잠근다. 자동 잠금 시간을 바꾸면 열린 다른 탭도 바로 새 시간으로 잰다. |
| 데스크톱 앱 | 자동 잠금. 생체 인증(Windows Hello)은 데스크톱 패키징 단계에서 정한다. |
| macOS | 생체 인증(Touch ID)과 자동 잠금. 백그라운드는 앱이 비활성이 될 때(다른 앱으로 전환, 앱 숨김)다. 앱 안의 저장·열기 패널이나 경고창이 키 창을 가져가는 것은 백그라운드가 아니다. |
| Android | 해당 클라이언트를 구현할 때 |

## 예외

1. 생체 인증을 등록하지 않은 기기는 마스터 비밀번호만 쓴다.

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 클라이언트 테스트 | 설정 시간이 지나면 잠기고 키가 메모리에서 지워짐; 백그라운드에서 타이머가 늦게 돌아도 다시 보일 때 경과 시간으로 잠김; 틀린 마스터 비밀번호로는 잠금이 풀리지 않음; 가입 직후와 볼트 없는 계정 로그인 시 빈 볼트 저장; 백그라운드 진입 시 가림 화면; 잠금 시 클립보드 즉시 비움; 오프라인 잠금 해제; 생체 정보 변경 시 생체 해제 무효화; 14일 경과 시 마스터 비밀번호 요구; 재시작 뒤 저장한 계정으로 잠금 화면; 세션 없이 온라인 잠금 해제 시 바로 로그인하고 인증 해시를 남기지 않음; 오프라인 잠금 해제 뒤 비밀번호 재입력으로 로그인; KDF 값이 다르거나 인증 실패면 비밀번호 바뀜 안내; 저장한 자동 잠금 시간이 재시작 뒤에도 유지됨; 잘못된 저장값은 기본 5분; 로그아웃해도 설정 유지 |
