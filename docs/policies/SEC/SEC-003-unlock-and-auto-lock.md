# SEC-003 잠금 해제 및 자동 잠금 정책
- 상태: 확정
- 규칙: 잠금은 메모리의 암호화 키를 지우고 볼트 화면을 가리는 것이며, 로그아웃과 달리 세션 토큰은 유지해 잠금을 풀면 바로 동기화한다. 앱이 백그라운드에 있거나 조작이 없으면 설정한 시간 뒤 자동으로 잠그고, 백그라운드로 갈 때는 앱 전환 화면에 볼트 내용이 비치지 않도록 가림 화면을 씌운다. 잠금 해제는 마스터 비밀번호 또는 (켠 경우) 생체 인증으로 하며, 오프라인에서도 볼트 복호화 성공 여부로 확인한다. 이 확인이 항상 가능하도록 모든 계정은 볼트를 가진다: 가입 직후 빈 볼트를 저장하고, 볼트가 없는 계정으로 로그인하면(가입 직후 저장이 실패한 경우 등) 볼트를 여는 화면으로 넘어가기 전에 빈 볼트를 저장한다. 잠긴 동안 클라이언트 메모리에는 이메일, KDF 값(salt·반복 횟수), 세션 토큰, 암호화된 볼트만 남기며 암호화 키·평문 볼트·인증 해시는 남기지 않는다. 잠기면 클립보드를 즉시 비운다. 기기에 생체 정보가 새로 등록되면 생체 해제를 무효화하고 마스터 비밀번호를 요구한다. 웹은 새로고침·재시작 뒤 기기에 저장한 계정으로 잠금 화면을 연다(ADR-0019). 이때는 세션 토큰이 없으므로, 온라인이면 잠금 해제 때 만든 인증 해시로 바로 로그인하고 응답을 받는 즉시 지운다. 오프라인이거나 서버에 닿지 못하면 인증 해시를 바로 지우고 볼트만 연 뒤, 동기화하려면 마스터 비밀번호를 다시 입력받아 로그인한다. 인증 해시는 이 요청 밖으로 메모리에 남기지 않는다. 로그인 전 서버가 준 KDF 값이 기기에 저장한 값과 다르거나 로그인이 인증 실패로 거절되면 마스터 비밀번호가 바뀐 것으로 보고 로그인 화면으로 보낸다.
- 값: 자동 잠금 기본 5분(선택: 즉시·1분·5분·15분·1시간, "잠그지 않음"은 없음, 마지막 조작부터 잰다. "즉시"는 백그라운드로 가는 순간 잠근다); 생체 인증 기본 꺼짐(가입 직후 켤지 묻는다); 생체 인증을 켜도 14일마다 한 번 마스터 비밀번호 요구; 생체 해제용 키는 이 기기 전용 저장소(iOS는 생체 인증으로 보호되는 Keychain, ThisDeviceOnly, iCloud 동기화·백업 제외)
- 적용 범위: iOS(생체 인증과 자동 잠금), 웹 브라우저(자동 잠금, 새로고침·탭 닫기·페이지 떠남·탭 동결 시 바로 잠김), 데스크톱 앱(자동 잠금, Windows Hello는 데스크톱 패키징 단계), macOS·Android는 해당 클라이언트 구현 시
- 예외: 생체 인증이 등록되지 않은 기기는 마스터 비밀번호만 쓴다
- 사용자 문구:
  - 잠금 화면: 제목 "볼트가 잠겼습니다" / 버튼 "Face ID로 잠금 해제", "마스터 비밀번호 입력"
  - 비밀번호 오류: 본문 "마스터 비밀번호가 올바르지 않습니다."
  - 빈 볼트 저장 실패(가입 직후): 본문 "계정은 만들었지만 볼트를 준비하지 못했습니다. 다시 로그인해 주세요."
  - 다시 입력 요청(세션 없이 열림): 본문 "서버와 동기화하려면 마스터 비밀번호를 다시 입력해 주세요." / 버튼 "동기화"
  - 비밀번호 바뀜: 본문 "마스터 비밀번호가 바뀌었습니다. 새 비밀번호로 로그인해 주세요."
- 근거: docs/adr/ADR-0010-client-composition-ios-and-shared-web.md; docs/vault-spec.md
- 검증 방법: 클라이언트 테스트(설정 시간 경과 후 잠기고 키가 메모리에서 지워짐, 백그라운드에서 타이머가 늦게 돌아도 다시 보일 때 경과 시간으로 잠김, 틀린 마스터 비밀번호로는 잠금 해제되지 않음, 가입 직후와 볼트 없는 계정 로그인 시 빈 볼트 저장, 백그라운드 진입 시 가림 화면, 잠금 시 클립보드 즉시 비움, 오프라인 잠금 해제, 생체 정보 변경 시 생체 해제 무효화, 14일 경과 시 마스터 비밀번호 요구, 웹 새로고침 뒤 저장한 계정으로 잠금 화면, 세션 없이 온라인 잠금 해제 시 바로 로그인하고 인증 해시를 남기지 않음, 오프라인 잠금 해제 뒤 비밀번호 재입력으로 로그인, KDF 값이 다르거나 인증 실패면 비밀번호 바뀜 안내)
- 비고: SEC-001, COM-001, ADR-0010, ADR-0019
- 이력: 2026-10-28 초기 등록; 2026-10-31 잠금 해제 확인을 위해 모든 계정이 볼트를 갖는 규칙, 잠긴 동안 메모리에 남기는 값, 자동 잠금 시간 기준 추가; 2026-10-31 가입 직후 빈 볼트 저장 실패 문구 추가; 2026-11-01 웹 재시작 뒤 기기 기록으로 잠금 화면, 세션 없는 잠금 해제와 비밀번호 재입력, 비밀번호 바뀜 감지 추가 (ADR-0019)
