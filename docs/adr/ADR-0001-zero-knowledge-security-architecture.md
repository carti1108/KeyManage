### ADR-0001 영지식(Zero-Knowledge) 클라이언트 암호화 아키텍처 채택
- 상태: 채택
- 날짜: 2026-10-27
- 배경: 패스워드 매니저는 사용자의 모든 민감한 계정 자격증명을 다루므로, 서버 침해나 네트워크 스니핑이 발생하더라도 사용자의 평문 비밀번호가 절대 유출되지 않는 절대적 보안 보장이 필요했다.
- 결정: 마스터 키 유도(PBKDF2/Argon2) 및 데이터 암·복호화(AES-GCM)는 전적으로 클라이언트 내부에서만 수행하고, 백엔드 서버에는 오직 암호화된 볼트 덩어리(Ciphertext)만 전송 및 보관하는 영지식(Zero-Knowledge) 아키텍처를 채택한다.
- 고려했던 대안: (1) 서버 중앙 암호화 방식 — 백엔드 API로 평문 비밀번호나 마스터 키를 전송받아 서버에서 암호화해 DB에 저장하는 방식. 클라이언트 구현은 단순해지나 서버 침해 시 모든 사용자 암호가 노출되는 치명적인 보안 결함이 있어 기각. (2) 완전 로컬 저장(동기화 없음) — 서버와의 동기화 없이 기기 로컬에만 저장하는 방식. 기기 분실 시 데이터 복구가 불가능하고 멀티 디바이스 확장이 막혀 기각.
- 결과: 서버 DB가 완전히 탈취되더라도 공격자가 복호화 키를 얻을 수 없어 강력한 보안성을 달성한다. 반면 사용자가 마스터 키를 분실했을 때 서버에서 복구해줄 수 없으며, 클라이언트 플랫폼마다 표준 암호화 라이브러리(CryptoKit 등)를 직접 구현해야 하는 비용이 발생한다.
- 관련: SEC-001
