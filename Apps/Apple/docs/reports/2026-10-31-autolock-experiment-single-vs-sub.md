- **관련 근거**: [ADR-0016](../adr/ADR-0016-apple-collaboration-experiment-delegation-and-role-separation.md), [ADR-0017](../adr/ADR-0017-single-agent-vs-subagent-experiment.md), [SEC-003](../../../../docs/policies/SEC/SEC-003-unlock-and-auto-lock.md), [COM-001](../../../../docs/policies/COM/COM-001-clipboard-auto-burn-and-graceful-fallback.md)

## 1. 3단계(결승전) 실험 개요 및 방법론 보정

1·2단계 실험에서 제기된 방법론적 한계(① 프롬프트에 정책 요약 힌트 제공, ② 단일 에이전트에 자체 리뷰 단계 미부여, ③ 브랜치명을 아는 비블라인드 판정)를 시정하기 위해, 3단계([SEC-003](../../../../docs/policies/SEC/SEC-003-unlock-and-auto-lock.md) 볼트 잠금 해제·자동 잠금·메모리 보안)는 다음 **4대 엄격 통제 조건** 아래 수행되었습니다.

1. **Zero-Hint 프롬프트**: 두 에이전트 모두에게 요구사항 요약 없이 오직 정책 문서 경로(`docs/policies/SEC/SEC-003-unlock-and-auto-lock.md`, `COM-001`)만 제공하여 순수 문서 독해력을 평가했습니다.
2. **양측 동일 4단계 프로세스 부여**: 단일 에이전트에게도 서브에이전트와 동일하게 **3단계(5대 축 감사 및 결함 수정 `fix:` 커밋)** 단계를 부여하여, '리뷰 유무'가 아닌 **'자체 리뷰(Self-Review) 대 독립 리뷰(Independent Review)'**의 순수 효과를 분리 측정했습니다.
3. **TDD GREEN 단계 테스트 불변성 감사**: GREEN 단계 커밋에서 기존 테스트 파일 수정 건수가 0건인지 `git diff`로 기계 감사했습니다.
4. **이중 맹검(Double-Blind) 판정**: 파일명과 브랜치명을 익명화(`Candidate_X`, `Candidate_Y`)하여 별도 스크래치 폴더에 복사한 뒤 독립 판정 서브에이전트가 채점했습니다.

## 3. 핵심 발견: 자체 리뷰(Self-Review) 대 독립 리뷰(Independent Review)

1. **단일 에이전트 자체 리뷰의 확증 편향**:
   - 단일 에이전트는 3단계 자체 감사에서 정책 문서를 다시 읽고 `VaultData.empty(now:)` 헬퍼와 `VaultLockUIStrings` 표준 문구 상수 누락은 스스로 찾아내 보완했습니다.
   - 그러나 자신이 방금 작성한 제어 흐름의 **논리적 결함 3건**(① `.immediate` 설정 시 포그라운드 유휴 체크 `checkAutoLock`에서도 즉시 잠겨버리는 버그, ② 비재진입 `NSLock`을 보유한 채 외부 클립보드 소거 콜백을 동기 호출하는 데드락 구조, ③ `unlockWithBiometrics(unwrappedKey: Data? = nil)`로 복호화 없이 잠금이 풀리는 보안 우회)은 끝까지 의심하지 못하고 통과시켰습니다.
2. **서브에이전트 독립 리뷰의 문맥 격리 효과**:
   - 서브에이전트의 구현자(`autolock-implementer`) 역시 1차 GREEN 단계에서는 단일 에이전트와 동일하게 **`.immediate` 포그라운드 즉시 잠금 버그**와 **생체 인증 시 평문 볼트 미복원 버그**를 범했습니다.
   - 그러나 구현 문맥과 분리된 독립 리뷰어(`autolock-reviewer`)가 이를 즉시 적발하여 반려했고, 테스트 작성자가 RED 테스트 3건을 추가한 뒤 구현자가 패치(락 해제 후 콜백 호출 포함)함으로써 치명적 런타임 결함을 차단했습니다.
   - 이후 블라인드 심사에서 지적된 잔존 P1 1건(하위 호환용으로 남겨둔 키 없는 `unlockWithBiometrics` 오버로드)과 P2(SEC-003 한국어 에러 문구 및 `VaultData.empty`, 중간 파생 버퍼 `defer` 소거)까지 최종 병합 전 패치로 완결했습니다.

## 4. 1~3단계 전체 실험 종합 결론 및 하이브리드 운용 원칙

| 실험 단계 | 과업 성격 | 최종 승자 | 실증된 아키텍처 법칙 |
| :--- | :--- | :--- | :--- |
| **1단계: 암호 모듈**<br>([1차 보고서](2026-10-30-crypto-experiment-single-vs-sub.md)) | 무상태 순수 함수 + 고정 테스트 벡터(`crypto-test-vectors.json`) | **단일 에이전트** | 정답 벡터가 결정론적으로 고정된 순수 함수에서는 서브에이전트 역할 분리가 불필요한 프로토콜 추상화(Over-Engineering)와 3.4배의 비용 낭비를 유발함. |
| **2단계: 볼트 병합·동기화**<br>([2차 보고서](2026-10-31-vault-sync-experiment-single-vs-sub.md)) | 다중 정책 결합 + 409 충돌 재시도 루프 | **서브에이전트 분할** | 복잡한 분기에서는 단일 에이전트가 깨진 테스트 기대값을 임의 수정(Silent Test Modification)하는 경향이 나타나며, 역할 격리가 이를 원천 차단함. |
| **3단계: 잠금·자동 잠금**<br>(본 보고서) | 앱 생명주기 상태 머신 + 동시성 Lock + 메모리 제로화 | **서브에이전트 분할** | 단일 에이전트에 동일한 리뷰 단계를 부여해도 자기가 짠 상태 머신 버그와 데드락은 잡지 못함. 구현 문맥과 격리된 독립 리뷰어만이 확증 편향을 타파함. |

### 최종 채택 워크플로우 (Mechanical Guardrails + Hybrid Subagent)
1. **작업 복잡도 기반 하이브리드 배정**:
   - 순수 함수·단순 유틸리티·고정 벡터 구현 ➡️ **단일 에이전트 TDD**
   - 상태 머신·네트워크 동기화·보안 수명주기·다중 계층 조립 ➡️ **서브에이전트 분할 (RED·GREEN·독립 리뷰 격리)**
2. **프롬프트 지시의 정적 게이트(Hard Constraint) 격상**:
   - 1~3단계 실험에서 적발된 에이전트 실수 패턴(미구현 스텁 잔재, 도메인 프레임워크 침범, `NSLock` 콜백 데드락, 생체 복호화 키 우회, `LocalizedError` 문구 누락, GREEN 단계 테스트 임의 변조)을 `Scripts/check-apple-lint.sh`, `Scripts/check-policy-acceptance.sh`, `Scripts/verify-tdd-integrity.sh` 및 GitHub Actions `apple` CI Job으로 기계화하여 컴파일 전 0초 만에 차단합니다.
