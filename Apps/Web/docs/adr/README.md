# 웹 클라이언트 아키텍처 결정 기록 (ADR)

웹 클라이언트에만 해당하는 기술·구조 결정을 모은다. 시스템 전체에 영향을 주는 결정은 공통 ADR([`docs/adr/`](../../../../docs/adr/README.md))에 쓴다.

## 작성 규칙

1. 형식과 불변 원칙은 공통 ADR의 작성 규칙을 따른다. 채택한 ADR은 고치지 않고, 결정이 바뀌면 새 ADR을 쓴다.
2. 새 ADR 번호는 `ADR-WEB-<세 자리 순번>`이다(`ADR-WEB-001`부터 발급). 다른 플랫폼과 번호가 겹치지 않는다.
3. ADR-0012·0013·0018~0020은 공통 순번 시절에 쓴 웹 결정이라 원래 번호를 그대로 쓴다. 데스크톱 앱(Tauri)은 웹 클라이언트를 감싸므로 여기에 둔다.
4. 공통 정책·공통 ADR만 참조한다. 다른 플랫폼 문서는 참조하지 않는다.
