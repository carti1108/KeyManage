# Android 실기기 확인 체크리스트

단위 테스트로 볼 수 없는 화면 배치와 기기 동작을 확인한다. 로컬 서버(`docker compose up -d`)와 `adb reverse tcp:8080 tcp:8080`이 필요하다.

## 확인 기록 (2026-11-20, 에뮬레이터)

| 항목 | 내용 |
| :--- | :--- |
| 기기 | 에뮬레이터 `Medium_Phone_API_37.0`, 앱 0.1.0(#154 빌드) |
| 방법 | 화면은 접근성 트리(`uiautomator dump`)로 읽고 `adb shell input`으로 조작했다. 앱 창이 화면 캡처를 막아(`FLAG_SECURE`) 모양·색·잘림은 보지 못했다. |
| 다른 기기 | 에뮬레이터 Chrome에서 연 웹 클라이언트(`http://localhost:8080`) |
| 오프라인 | 비행기 모드 대신 `adb reverse --remove tcp:8080`으로 서버 연결만 끊었다. 앱은 요청 실패로 오프라인을 판단한다. |
| 되돌림 | 서버의 계정 볼트 파일(`/data/vaults/<id>.json`)을 한 revision 앞의 사본으로 덮어써 재현했다. |
| 결과 | 49개 중 통과 31, 실패 4, 일부만 확인 2, 미확인 12 |

표시: `[x]` 통과. `[ ]` 뒤에 **실패**·**일부**·**미확인**과 사유를 적었다.

## 1. 가입·로그인 (SEC-001, SEC-002)

- [x] 가입 화면에서 비밀번호를 입력하면 강도 게이지가 바뀐다
- [ ] 약한 비밀번호로는 가입 버튼이 눌리지 않고 안내 문구가 보인다 — **일부**: 8자 비밀번호에서 "취약함" 게이지와 안내 문구가 보이고 가입되지 않는다. 다만 버튼은 비활성이 아니라 눌리며, 누르면 "마스터 비밀번호는 12자 이상이어야 합니다."가 나온다. 12자 이상이면서 약한 비밀번호는 시험하지 않았다.
- [x] 가입 직후 빈 볼트 목록이 열린다
- [ ] 가입 직후 "생체 인증으로 잠금을 풀까요?" 대화상자가 뜬다(지문이 등록된 기기) — **미확인**: 지문을 등록하지 않았다. 등록하지 않은 기기에서는 대화상자가 뜨지 않았다.
- [x] 로그아웃 뒤 같은 계정으로 로그인하면 항목이 그대로 보인다
- [x] 틀린 비밀번호로 로그인하면 오류 문구가 보이고 화면이 멈추지 않는다
- [ ] 키보드가 올라와도 입력 칸과 버튼이 가려지지 않는다 — **미확인**: 로그인 화면은 키보드가 올라오면 배치가 위로 올라가는 것까지 좌표로 확인했다. 실제로 가려지는지는 화면을 보지 못해 판단하지 않았다.

## 2. 볼트 목록·항목 (VLT-001)

- [x] `+` 버튼으로 항목을 추가하면 목록에 보인다
- [x] 서비스 이름을 비우고 저장하면 "서비스 이름을 입력해 주세요."가 보인다
- [x] 폼의 비밀번호 생성 버튼이 비밀번호 칸을 채운다
- [x] 항목을 수정하면 상세와 목록에 반영된다
- [x] 삭제는 확인 대화상자를 거치고, 취소하면 남는다
- [x] 검색어로 서비스 이름·아이디가 걸러진다
- [x] 뒤로 가기가 편집 → 상세 → 목록 순서로 돈다
- [ ] 항목이 많을 때 목록이 스크롤되고 `+` 버튼이 마지막 줄을 가리지 않는다 — **실패**: 스크롤은 된다. 맨 아래에서 `+` 버튼이 마지막 줄의 비밀번호 복사 버튼을 가린다(#157).

## 3. 클립보드 (COM-001)

- [ ] 아이디·비밀번호 복사 뒤 "클립보드 보안 소각" 안내와 남은 초 배지가 보인다 — **실패**: 목록·상세·생성기 어디서 복사해도 안내와 배지가 나타나지 않는다(#156).
- [ ] 30초 뒤 다른 앱에 붙여 넣으면 값이 없다 — **실패**: 36초 뒤 붙여 넣어도 복사한 값이 그대로 나온다(#156). 다른 앱이 아니라 이 앱의 검색 칸에 붙여 넣어 확인했다.
- [ ] 30초 안에 다른 값을 복사하면 배지가 사라지고 그 값은 지워지지 않는다 — **미확인**: 타이머가 돌지 않아 판단할 수 없다. #156을 고친 뒤 다시 본다.

## 4. 잠금·자동 잠금 (SEC-003)

- [x] 잠금 버튼을 누르면 잠금 화면으로 가고, 마스터 비밀번호로 풀린다
- [x] 틀린 비밀번호는 "마스터 비밀번호가 올바르지 않습니다."를 보인다
- [x] 설정에서 자동 잠금 시간을 바꾸면 그 시간 뒤 잠긴다 — 1분으로 바꿔 50초에는 열려 있고 75초에는 잠긴 것을 확인했다.
- [x] 앱을 뒤로 보냈다가 시간이 지난 뒤 돌아오면 잠겨 있다
- [x] 앱을 완전히 끄고 다시 열면 잠금 화면에서 시작한다
- [x] 최근 앱 화면에 볼트 내용이 보이지 않는다 — 창에 `SECURE` 플래그가 걸린 것으로 확인했다. 최근 앱 화면을 직접 보지는 않았다.

## 5. 생체 해제 (SEC-003, ADR-AND-002)

에뮬레이터에 기기 PIN과 지문을 등록해야 한다. 기기 보안 설정은 사람이 바꾼다.

- [ ] 설정에서 생체 인증을 켜면 인증 창을 거쳐 켜진다 — **미확인**
- [ ] 잠금 화면에 "생체 인증으로 잠금 해제" 버튼이 보이고 지문으로 풀린다 — **미확인**
- [ ] 인증 창을 취소하면 잠금 화면에 그대로 남는다 — **미확인**
- [ ] 기기에 지문을 새로 등록하면 생체 해제가 꺼지고 비밀번호를 요구한다 — **미확인**
- [ ] 설정에서 끄면 잠금 화면의 버튼이 사라진다 — **미확인**

## 6. 오프라인·동기화 (VLT-002, VLT-003)

- [x] 비행기 모드에서 항목을 저장하면 저장되고 "오프라인 상태입니다. 변경 사항이 서버에 동기화되지 않습니다."가 보인다 — 서버 연결을 끊은 직후에는 살아 있던 연결로 저장이 그대로 전송될 수 있다. 앱을 다시 띄운 뒤 확인한다.
- [x] 비행기 모드를 끄고 다시 저장하면 경고가 사라지고 웹(localhost:8080)에서 항목이 보인다
- [x] 비행기 모드에서 앱을 껐다 켜도 잠금이 풀리고 대기 중인 변경이 남아 있다
- [x] 웹에서 항목을 바꾼 뒤 Android에서 다른 항목을 저장하면 둘 다 남는다(자동 병합)
- [x] 세션 없이 열렸을 때 "동기화" 안내 띠가 보이고, 누르면 비밀번호를 다시 받는다

## 7. 되돌림 경고 (VLT-001 규칙 9)

서버 데이터를 지웠다가 옛 상태로 되돌려야 재현된다(`docker compose down -v` 뒤 같은 계정을 다시 만드는 식으로는 계정이 달라져 재현되지 않는다).

- [x] 잠금 해제 때 "서버 볼트가 이전 상태로 돌아감" 대화상자가 뜬다
- [x] "취소"를 누르면 잠금 화면에 남고 볼트가 열리지 않는다
- [x] "서버 볼트 받아들이기"를 누르면 볼트가 열린다
- [ ] 생체 해제에서 받아들이면 생체 인증 창이 한 번 더 뜬 뒤 열린다 — **미확인**: 5장과 같은 이유
- [x] 볼트 목록에서 저장 중 되돌림이면 안내 띠에 두 버튼이 잘리지 않고 보인다 — 두 버튼의 좌표가 화면 안에 온전한 크기로 잡히는 것으로 확인했다.

## 8. 백업·계정 (VLT-004, SEC-004, SEC-005)

- [x] 백업 내보내기가 파일 선택 창을 거쳐 파일을 만든다
- [x] 그 파일을 복원하면 비밀번호를 묻고 항목이 돌아온다
- [x] 웹에서 내보낸 백업 파일을 Android에서 복원할 수 있다
- [x] 마스터 비밀번호를 바꾼 뒤 새 비밀번호로만 잠금이 풀린다
- [x] 계정 삭제 뒤 로그인 화면으로 가고 같은 계정으로 로그인되지 않는다

## 9. 화면 공통

- [ ] 다크 모드에서 글자와 버튼이 모두 읽힌다 — **미확인**: 화면을 보지 못한다
- [ ] 글자 크기를 가장 크게 해도 버튼 글자가 잘리지 않는다 — **미확인**: 화면을 보지 못한다
- [ ] 화면을 돌려도 입력하던 내용과 화면이 유지된다 — **실패**: 화면을 돌리면 볼트가 잠기고 입력하던 내용이 사라진다(#159).
- [ ] TalkBack이 안내 띠와 오류 문구를 읽는다 — **미확인**: TalkBack을 켜지 않았다
- [ ] 비밀번호 생성기 탭에서 길이·문자 종류를 바꾸면 결과가 바뀌고 복사된다 — **일부**: 길이와 문자 종류에 따라 결과가 바뀐다. 복사 뒤 남은 초 배지는 나타나지 않았고(#156), 복사된 값은 붙여 넣어 확인하지 않았다.
