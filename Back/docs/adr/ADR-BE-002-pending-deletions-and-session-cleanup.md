### ADR-BE-002 지우지 못한 볼트는 삭제 예정 목록에 남겨 시작 때 지우고, 계정이 없거나 만료된 세션 파일도 시작 때 정리한다
- 상태: 채택
- 날짜: 2026-11-02
- 영역: 백엔드

> **요약** 계정 삭제나 비밀번호 변경 뒤 볼트 파일을 지우지 못하면 그 볼트 ID를 삭제 예정 목록 파일에 적는다. 서버는 시작할 때 계정 수와 관계없이 목록에 적힌 ID만 지운다. 같은 시작 단계에서 계정이 없거나 만료된 세션 파일도 지운다.

#### 배경

ADR-BE-001의 고아 볼트 정리는 저장 폴더 설정 오류로 모든 볼트를 지우지 않으려고 계정이 하나도 없으면 건너뛴다. 그래서 마지막 남은 계정을 지울 때(SEC-005) 볼트 삭제가 실패하면 그 볼트는 계속 남아, SEC-005 규칙 4("서버가 정리한다")를 지키지 못한다. 또 로그인이 계정 삭제와 겹치거나 세션 삭제가 실패하면, 이메일이 평문으로 든 세션 파일이 무효인 채 남는다. 만료 세션을 일괄 정리하는 기능도 없다.

#### 결정

1. **삭제 예정 목록:** 확정 뒤 볼트 삭제가 실패하면 그 볼트 ID를 인증 저장 폴더의 삭제 예정 목록 파일에 원자적으로 추가한다(`AtomicFiles`). 볼트 ID 외의 정보는 적지 않는다.
2. **시작 때 처리:** 서버는 요청을 받기 전에 목록의 볼트 ID를 지우고, 지운 ID를 목록에서 뺀다. 계정 수와 관계없이 하며, 지금 어느 계정이 가리키는 볼트 ID는 지우지 않는다. 목록에 적힌 ID만 지우므로 설정 오류에도 다른 볼트를 지우지 않는다.
3. **기존 고아 정리 유지:** ADR-BE-001의 고아 볼트 정리(계정이 있을 때 참조되지 않는 볼트 삭제)는 그대로 둔다.
4. **세션 정리:** 같은 시작 단계에서 만료됐거나, 형식이 잘못됐거나, 계정이 없거나, 계정의 볼트 ID와 다른 세션 파일을 지운다. 계정 파일을 하나라도 읽지 못하면 세션 정리를 건너뛴다.

#### 고려했던 대안

| 대안 | 고르지 않은 이유 |
| :--- | :--- |
| 계정이 0개여도 고아 정리 실행 | 인증 저장 폴더 설정이 잘못되면 모든 볼트를 지운다. |
| 요청 안에서 다시 시도만 | 디스크 오류가 이어지면 여전히 남는다. 다시 시도는 목록과 함께 쓸 수 있지만 목록 없이는 보장이 없다. |
| 한계로 문서화만 | 정책 규칙 4를 지키지 못하는 경우가 남는다. |
| 세션 파일에 이메일 색인을 두고 즉시 정리 | 저장 형식이 늘고, 시작 때 정리로 충분하다. |

#### 결과

- 장점: 마지막 계정을 지울 때도 볼트가 남지 않는다. 무효 세션 파일(이메일 평문)이 쌓이지 않는다.
- 비용: 삭제 예정 목록 파일 하나가 늘고, 시작 시간이 세션 수에 비례해 늘어난다(데모 규모에서는 작다). 목록 파일 쓰기마저 실패하면 그 볼트는 다음 고아 정리(계정이 있을 때)까지 남는다.
