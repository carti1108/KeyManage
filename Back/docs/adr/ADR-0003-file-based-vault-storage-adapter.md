### ADR-0003 파일 기반 단일 암호화 볼트 저장소 어댑터 채택
- 상태: 채택
- 날짜: 2026-10-27
- 배경: 백엔드 서버는 영지식 아키텍처 원칙에 따라 사용자 암호의 개별 필드를 알 필요가 없으며, 오직 클라이언트가 전달한 '암호화된 볼트 바이너리/문자열(Ciphertext)'만 온전히 저장하고 조회할 수 있으면 된다.
- 결정: 포트-어댑터 구조의 Outbound Port(`VaultRepositoryPort`)를 정의하고, 초기 구현체로 외부 RDBMS 종속성 없는 가벼운 파일 기반 저장소 어댑터(`FileSystemVaultRepository`)를 채택한다.
- 고려했던 대안: (1) RDBMS (PostgreSQL, MySQL) 테이블 구축 — 개별 필드가 암호화된 상태에서 관계형 테이블을 분리하는 것은 과도한 엔지니어링이며, 로컬 컨테이너 및 DB 관리 비용이 발생하여 기각. (2) Redis 인메모리 저장소 — 속도는 빠르나 메모리 한계 및 영속성 보장을 위해 디스크 스냅샷 설정이 복잡해져 기각.
- 결과: 별도 DB 설치나 Docker 인프라 없이 단독으로 백엔드가 즉시 구동되고 배포가 단순해진다. 향후 클라우드 RDBMS나 분산 오브젝트 스토리지(S3 등)로 변경이 필요하더라도 도메인 코드 수정 없이 어댑터만 갈아끼울 수 있다.
- 관련: ADR-0001, ADR-0002
